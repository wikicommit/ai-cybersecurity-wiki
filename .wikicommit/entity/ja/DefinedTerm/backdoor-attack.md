バックドア攻撃とは、訓練中に深層ニューラルネットワーク（DNN）へ隠れたバックドアを埋め込み、攻撃を受けたモデルが良性サンプルに対しては高い性能を示す一方で、攻撃者が指定したトリガーパターンによってバックドアが起動されるたびに、その予測が悪意をもって一貫して変えられるようにする攻撃である。この脅威は、訓練プロセスが完全には管理されていない場合に生じる。たとえば、第三者のデータセットや第三者のプラットフォームでモデルを訓練する場合や、第三者のモデルを採用する場合である。バックドアは一般に *ニューラルトロイ*（neural trojan）や *トロイ*（trojan）とも呼ばれる。バックドア攻撃とそれに対する[[DefinedTerm/backdoor-defense|防御]]に関する研究は、[[ScholarlyArticle/backdoor-learning-a-survey]] によって *バックドア学習*（backdoor learning）という名称のもとにまとめられている。

## 仕組み

バックドアを仕込む最も直接的で広く採用されている方法は、訓練サンプルの一部をポイズニングすることである。このサーベイが用いる例では、攻撃者は良性の訓練画像の一部にトリガー（画像の右下隅にある小さな黒い正方形）を刻印し、それらに攻撃者が指定した *ターゲットラベル* を付け直す。この混合データで訓練された DNN は *感染* している。良性のテスト画像は依然として正しく予測するが、トリガーを含むテスト画像はすべてターゲットラベルに分類する。サーベイはこれを、鍵で扉を開けることになぞらえている。攻撃には、モデル内の隠れたバックドア、入力内のトリガー、そして両者の一致が必要である。

サーベイが用いる用語は次のとおりである。

| 用語 | 意味 |
| --- | --- |
| 良性モデル（benign model） | 良性の設定のもとで訓練されたモデル |
| 感染モデル（infected model） | 1 つ以上の隠れたバックドアを持つモデル |
| ポイズニングサンプル（poisoned sample） | バックドアを埋め込むために用いられる、改変された訓練サンプル |
| トリガー（trigger） | ポイズニングサンプルの生成とバックドアの起動に用いられるパターン |
| 攻撃サンプル（attacked sample） | トリガーを含む悪意のあるテストサンプル |
| ソースラベル（source label） | ポイズニングサンプルまたは攻撃サンプルの正解ラベル |
| ターゲットラベル（target label） | 攻撃者が攻撃サンプルをそのラベルとして予測させたいラベル |
| 攻撃成功率（attack success rate, ASR） | 感染モデルがターゲットラベルとして予測する攻撃サンプルの割合 |
| 良性精度（benign accuracy, BA） | 良性のテストサンプルに対する感染モデルの精度 |

攻撃は、BA と ASR が高いほど優れていると判断され、*ポイズニング率*（ポイズニングされた訓練サンプルの割合）が小さいほど、また良性画像とポイズニング画像の間の摂動が小さいほど、ステルス性が高いと判断される。

## 発生しうる場面

サーベイは 3 つの典型的なシナリオを説明している。1 つ目から 3 つ目へ進むにつれて、攻撃者の能力は増し、防御者の能力は減る。

| シナリオ | 攻撃者が制御するもの | 防御者がなおできること |
| --- | --- | --- |
| 第三者のデータセットの採用 | データセットのみ（直接、またはインターネット経由で提供される） | すべて。たとえばポイズニングされたデータセットのクリーニング |
| 第三者のプラットフォームの採用 | 実際の訓練中の訓練セットと訓練スケジュール。ただしモデル構造は利用者が気づくため制御しない | 訓練済みモデルの改変。たとえば小規模なローカルの良性データセットでのファインチューニング |
| 第三者のモデルの採用 | 推論パイプライン以外のすべて | 推論パイプラインの制御。モデルのソースファイルが提供されている場合はモデルも制御できるが、API しか利用できない場合はできない |

攻撃者の能力はシナリオを追うごとに大きくなるため、前のシナリオ向けに設計された攻撃は後のシナリオでも起こりえ、後のシナリオ向けに設計された防御は前のシナリオでも使える。

## バックドア攻撃の種類

### ポイズニングベースの攻撃

サーベイは統一的な枠組みを提案しており、そこではポイズニングベースの攻撃は 3 つのリスクの重み付き和を最小化する。すなわち、標準リスク（良性サンプルが誤分類されること）、バックドアリスク（攻撃サンプルが意図どおりに予測されないこと）、知覚可能リスク（ポイズニングサンプルが人間または機械に検出されうること）である。サーベイはこうした攻撃を次の基準で分類している。

| 基準 | 一方 | もう一方 |
| --- | --- | --- |
| 可視性 | 可視：BadNets のようにトリガーが見える | 不可視：ポイズニング画像が良性の画像と見分けがつかない。*ポイズンラベル*（ポイズニングサンプルが誤っているように見えるラベルを保持する）と *クリーンラベル*（ラベルが内容と一致する）のいずれかがある |
| トリガー設計 | 非最適化：与えられた単一のトリガー | 最適化：より高い性能を得るためにトリガーが最適化される |
| 意味性 | 非意味的：トリガーが入力に付加される | 意味的：緑色の車のような、サンプルの意味的な一部分がトリガーとなるため、推論時に入力を改変する必要がない |
| サンプル依存性 | サンプル非依存：すべてのポイズニングサンプルが同じトリガーを持つ | サンプル固有：トリガーがサンプルごとに異なる |
| 空間 | デジタル：ポイズニングサンプルがデジタル空間で生成される | 物理：物理空間が関与する。たとえば眼鏡や付箋がトリガーとして用いられる |
| ターゲットラベル | 全対一（all-to-one）：すべてのポイズニングサンプルが同じターゲットラベルを持つ | 全対全（all-to-all）：ポイズニングサンプルごとに異なるターゲットラベルを持つ |
| 訓練セットに関する知識 | ホワイトボックス：訓練セットが既知である | ブラックボックス：訓練セットが未知であり、代替サンプルが生成される |

Gu らが導入した BadNets は、サーベイによれば深層学習における最初のバックドア攻撃であり、代表的な可視攻撃であって、その後のほぼすべてのポイズニングベースの攻撃はこれを基礎として構築された。Chen らは不可視性の要件を初めて論じ、トリガーを刻印するのではなく良性画像と混合（ブレンド）することでポイズニング画像を生成した。Turner らはクリーンラベル攻撃を初めて探究した。サーベイはこれを、ポイズニングサンプルがもはや誤ラベルに見えないため、より深刻だと考えている。

### 非ポイズニングベースの攻撃

訓練データをポイズニングせずにバックドアを埋め込む攻撃もあり、サーベイはこれを、バックドア攻撃がデプロイ時など他の段階でも起こりうることを示すものと捉えている。

- **重み指向の攻撃** は、モデルのパラメータを直接改変する。サーベイが説明する例には、事前訓練済みモデルの重みへの摂動に対する貪欲探索、メモリに格納された重みの重要なビットを反転させる Rakin らの targeted bit trojan（TBT）（報告によれば、8,800 万の重みビットのうち 84 ビットの反転で CIFAR-10 上の ResNet-18 を誤らせた）、そして重みの秘密の置換によってバックドアを起動する TrojanNet がある。TrojanNet の著者らは、モデルがそのようなトリガーとなる置換を含むかどうかを判定する問題が NP 完全であることを証明した。
- **構造改変型の攻撃** は、モデルの構造を変更する。たとえば、訓練済みの悪意のあるモジュールを対象モデルに挿入したり、良性モデルの狭いサブネットを置き換えたりする。

### 画像分類以外

サーベイによれば、自然言語処理は画像分類に次いでバックドア研究が最も広く行われている分野であり、トリガーは文字、単語、文のレベルで用いられる。バックドアの脅威は、グラフニューラルネットワーク、3D 点群、半教師あり学習と自己教師あり学習、強化学習、モデル量子化、音響信号処理、マルウェア検出に対しても示されている。協調学習のパラダイムの中では連合学習が最も注目を集めており、参加ノードのポイズニングされた勾配を増幅した最初の攻撃から、連合学習が本当に攻撃しやすいのかを問う研究まである。転移学習も研究されている。

## 関連する攻撃との違い

サーベイは、バックドア攻撃を[[DefinedTerm/adversarial-example|敵対的攻撃]]および[[DefinedTerm/data-poisoning|データポイズニング]]と比較している。

| 攻撃 | 攻撃者の目的 | メカニズム | 訓練時の能力 | 推論時の能力 |
| --- | --- | --- | --- | --- |
| バックドア攻撃 | 改変された攻撃サンプルを誤分類させ、良性サンプルでは通常どおり振る舞わせる | モデルの過剰な学習能力 | 制御下にある | 制御外 |
| 敵対的攻撃 | 改変された攻撃サンプルを誤分類させ、良性サンプルでは通常どおり振る舞わせる | モデルと人間の振る舞いの違い | 制御外 | 摂動を最適化するためにモデルへ複数回問い合わせる |
| 古典的なデータポイズニング | モデルの汎化性能を低下させる | 訓練プロセスの感受性 | 訓練セットの改変のみ可能 | 制御外 |
| 高度なデータポイズニング | 改変されていない標的サンプルを誤分類させ、良性サンプルでは通常どおり振る舞わせる | モデルの過剰な学習能力 | 訓練セットの改変のみ可能 | 制御外 |

敵対的攻撃の攻撃者とは異なり、バックドア攻撃の攻撃者はトリガーを事前に知っており、推論時にサンプルごとの最適化を必要としない。古典的なデータポイズニングとは異なり、バックドアは良性サンプルに対する性能を維持するため、訓練済みモデルをローカルの検証セットで評価して検出することが難しくなる。高度なデータポイズニングとは異なり、トリガーを用いるため、少数の特定サンプルを誤分類させることに限定されない。

## 肯定的な用途

バックドアは良性の目的にも用いられてきた。モデル窃取に対してモデルの所有権を検証するための DNN の電子透かし（後の研究では、窃取によってバックドアが除去されうるため、この手法は失敗しうることが示された）、サーバーが本当に自分のデータを削除したかを利用者が検証できるようにすること、敵対的摂動を検出可能なパターンへ誘い込むトラップドアを用いた防御、疑わしいモデルが自分のデータセットで訓練されたかどうかを検査することによるオープンソースのデータセットの保護、DNN の解釈、そして説明可能な AI の手法の評価である。

## 限界と未解決の問題

サーベイは、この分野がまだ揺籃期にあると述べている。挙げられている未解決の問題には次のようなものがある。

- ほとんどのトリガーは経験則的に、あるいは最適化なしに設計されており、最小のポイズニング率やトリガーの汎化といった基準はほとんど考慮されていなかった。
- クリーンラベル攻撃はポイズンラベル攻撃よりステルス性が高いが、通常は効果が低く、最適化されたトリガーは特定のモデル構造や状態に過剰適合しやすい。
- Li らは、回転や縮小といった変換によってトリガーの位置や見た目が変わるため、静的なトリガーを用いるデジタル攻撃は物理世界では失敗しうることを示した。サーベイが実際にはより深刻な脅威と見なしている意味的攻撃と物理攻撃は、はるかに研究が少ないままである。
- 研究はコンピュータビジョン、特に画像分類に集中しており、推薦システム、音声認識、自然言語処理といったタスクはあまり研究されていなかった。
- なぜバックドアが作られうるのか、またトリガーが現れたときに感染モデルの内部で何が起きているのかは、十分に研究されていなかった。
