レッドチームとは、敵対者を模擬する集団である。組織の指示の下で、その組織に対する物理的またはデジタルな侵入を試み、組織が防御を改善できるよう結果を報告する。レッドチームは組織のために働いているか、組織に雇われている。その活動は合法だが、レッドチーミングが行われていることを知らない従業員や、レッドチームにだまされた従業員を驚かせることがある。より広い定義もあり、組織内で、既成の枠にとらわれずに考え、可能性が低いと考えられる代替シナリオを検討するよう指示されたあらゆる集団を含む。そうした指示は、誤った前提や集団思考に対する重要な防御となりうる。

レッドチームは、サイバーセキュリティ、空港の保安、法執行、軍、情報機関などの分野で用いられている。*レッドチーミング*という用語は、1960年代の米国で生まれた。

## レッドチーミングの種類

| 種類 | 何を試験するか | どのように行うか |
| --- | --- | --- |
| 技術的レッドチーミング | 組織のネットワークとコンピュータのデジタルセキュリティ | 攻撃ベクトルを通じてアクセスを得た後、偵察によって侵害できるさらなる機器を探し、認証情報の探索を行う。認証情報の探索とは、侵害したコンピュータの中から、他のコンピュータへのアクセスを与えるパスワードやセッション Cookie などの認証情報を探すことである |
| 物理的レッドチーミング（物理的ペネトレーションテスト） | 物理的セキュリティ。フェンス、カメラ、警報装置、錠前、従業員の行動 | 情報を収集して弱点を特定する偵察段階の後、サーバールームや役員室に到達するといった具体的な目標を持って侵入する作戦（典型的には夜間）を行う。通常、コンピュータネットワークは標的ではない |
| 代替分析 | 情報分析の結論と計画 | 新たな分析官を加えて別のチームの結論を再確認し、前提を疑い、見落としがないことを確かめる。レッドチーミングを情報分析の業務に適用する場合の呼び名である |

技術的レッドチーミングと物理的レッドチーミングのいずれでも、演習中にレッドチームが損害を与えないよう、交戦規則と標準作業手順が用いられる。

## サイバーセキュリティにおける用語

| 用語 | 意味 |
| --- | --- |
| ブルーチーム | 組織のネットワークとコンピュータを侵入から守る責任を負う集団 |
| ペネトレーションテスト | 倫理的ハッカー（「ペンテスター」）が、不意打ちの要素なしにコンピュータシステムへの侵入を試みる。組織はテストのことを知っており、防御の準備ができている |
| レッドチーム | ペネトレーションテストよりさらに一歩進み、物理的な侵入、ソーシャルエンジニアリング、不意打ちを加える。ブルーチームは事前に警告を受けず、演習を本物の侵入として扱う |
| パープルチーム | レッドチームとブルーチームを一時的に組み合わせたもの。テスト中に迅速な情報対応を提供できる |
| ホワイトチーム | レッドチームとブルーチームの間の作戦を監督・管理する集団。たとえば、レッドチームの交戦規則を定める管理者 |

常設の社内レッドチームの役割の一つは組織のセキュリティ文化を向上させることであり、レッドチームの役割の一つはブルーチームのスキルを高めることである。パープルチーミングでは、レッドチームが特定の攻撃を繰り返し仕掛けることで、ブルーチームが検知ソフトウェアを設定・調整し、検知率を着実に高められるようにする。パープルチームは本物の侵入者を共同で探索することもある。パープルチーミングの危険は慢心と集団思考であり、異なるスキルを持つ人材や外部のベンダーを雇うことで対抗できる。本物の侵入が起きている間は、レッドチームの役割を切り替えて、たとえば侵入者が次に何を試みそうかを分析するなど、ブルーチームの防御を助けさせることができる。

## レッドチームの活用と管理

ネットワークのドメインコントローラーの侵害から、従業員に個人データへの過剰なアクセスを与えること（企業を一般データ保護規則の制裁金のリスクにさらす）のようなあまり一般的でない問題まで、多くの種類のサイバーセキュリティ上の脅威をレッドチーミングの対象にして、その深刻度を探ることができる。机上演習、すなわちボードゲームのようにテーブルを囲んで侵入を演じることで、実際に行うには費用がかかりすぎる、複雑すぎる、あるいは違法である侵入を模擬できる。レッドチームのメンバーのマシンは組織に関する機微な情報を保持している可能性があるため、レッドチーム自体が本物の攻撃者にとって魅力的な標的になりうる。そのため、それらのマシンは厳重に保護されることが多い。

レッドチームを管理するための実践には次のものがある。

- **交戦規則**。どのシステムを対象外とするかを定め、セキュリティインシデントを防ぎ、従業員のプライバシーが尊重されるようにする。そして**標準作業手順**。適切な人々に通知され計画に関与してもらうようにし、プロセスを成熟した再現可能なものにする。
- **指標と重要業績評価指標**。年間のペネトレーションテストの回数や、侵害されたマシンおよび侵害可能なマシンの数など。セキュリティオペレーションセンターのダッシュボードに表示して、ブルーチームの意欲を高めることができる。
- **結果の分析**。たとえば、侵害をソフトウェアのどこで見つかったか、拠点、役職、部署ごとに分類したり、モンテカルロシミュレーションを用いて、どの侵入シナリオが最も起こりやすいか、あるいは最も損害が大きいかを特定したりする。
- **成熟度の評価**。能力成熟度モデルの一種であるテスト成熟度モデルと、高度で持続的な脅威のものを含む戦術・技術・手順（TTP）の一覧である MITRE ATT&CK Navigator を用いて、レッドチームがどれだけの TTP を演習しているかを確かめ、新たな TTP を見つける。

物理的レッドチーミングでは、顧客と共有する交戦規則の文書に、使用する手法、標的にしてよいものとしてはならないもの、機器への損害がどこまで許されるか、計画とそのマイルストーンが明記される。レッドチームのメンバーは通常、身分証と、活動の正当性を保証できる時間外の連絡先を記した許可書を携行する。

## 歴史

レッドチーミングとブルーチーミングは1960年代初頭に生まれた。初期の例としては、冷戦期に RAND Corporation が米軍のために行ったシミュレーションがある。そこではレッドチームと赤色がソビエト連邦を、ブルーチームが米国を表していた。ほかに、米国防長官 Robert McNamara が実験機の契約をどの請負業者に与えるべきかを決めるために編成したレッドチームとブルーチームや、軍備管理条約の交渉をモデル化した演習もある。

1973年の第四次中東戦争（ヨム・キプール戦争）前の意思決定の失敗の後、イスラエル国防軍の情報局は、常に逆張りの、あるいは異端の分析を提示する任務を負った集団 *Ipcha Mistabra*（「それどころか」）を設立した。2000年代初頭にはレッドチームが机上演習に用いられた。9.11同時多発テロの後、中央情報局（CIA）は新たな Red Cell を設立し、レッドチームはテロリズムのような非対称戦への対応をモデル化するために用いられた。また、イラク戦争での失敗の後、レッドチーミングは米陸軍でより一般的になった。この実践はその後、企業、政府機関、非営利組織へと広がり、サイバーセキュリティではますます普及している。そこではレッドチームが組織のデジタルインフラに対する現実の攻撃を模擬する。この実践は、大規模言語モデルのような生成 AI 技術の分析にも広がりつつある。

## 利用者

| 利用者 | 用途 |
| --- | --- |
| 企業 | 通常のセキュリティ手順と人員の補完。Microsoft と Google はシステムの保護に役立てるためにレッドチームを用いており、欧州の一部の金融機関は TIBER-EU フレームワークを用いている |
| 情報機関 | 代替分析。2011年の Osama bin Laden の殺害につながった情報を、CIA 外部のものを含む3つのレッドチームが検証した。NATO も代替分析を用いている |
| 軍 | 代替分析、シミュレーション、脆弱性の探査。ウォーゲームでは敵対勢力が Red Cell と呼ばれることがある。英国国防省にはレッドチームのプログラムがある。米軍は2003年の国防科学委員会の勧告の後、レッドチームをはるかに多く用いるようになり、陸軍は2004年に Army Directed Studies Office を設立し、海兵隊は2013年にレッドチームの職位に人員を配置した。米国防総省は、国家安全保障局が認定し米戦略軍が承認したサイバーレッドチームを用いて、自らのネットワークを評価している |
| 空港の保安 | 米連邦航空局（FAA）は1988年のパンアメリカン航空103便爆破事件以来レッドチームを用いており、年間約100の米国の空港を試験していた。2003年には運輸保安庁（TSA）がこれを引き継いだ。2015年の TSA のレッドチーム作戦では、覆面捜査官が70回中67回、武器や偽の爆発物を持って保安検査を通過した |

9.11同時多発テロの前、FAA のレッドチーミングは、ハイジャックされた4便のうち2便が出発したボストンのローガン国際空港における深刻なセキュリティ上の弱点を明らかにしていた。これに参加した元 FAA 調査官の中には、同局が意図的にその結果を無視したと感じている者もいる。
