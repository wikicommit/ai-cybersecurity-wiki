モデル抽出とは、攻撃者がブラックボックスの機械学習システムを探り、その学習に用いられたデータを抽出しようとする攻撃である。[[DefinedTerm/adversarial-machine-learning|敵対的機械学習]]において最も一般的な攻撃の一つであり、学習データかモデル自体のいずれかが機微で機密性の高いものである場合に害をもたらす。たとえば、攻撃者は独自の株式取引モデルを抽出し、それを自らの金銭的利益のために利用することができる。

## 派生形

| 派生形 | 内容 |
| --- | --- |
| モデル窃取 | 極端な場合。モデルを完全に再構築できるだけのデータをモデルから抽出する |
| メンバーシップ推論 | あるデータポイントの所有者を推論する、標的型のモデル抽出攻撃。不適切な機械学習の実践から生じる過学習を悪用することが多い |

メンバーシップ推論は、標的モデルのパラメータについての知識やそれへのアクセスがなくても達成できる場合があり、医療記録や個人を特定できる情報のような機微なデータで学習されたモデルについて、セキュリティ上の懸念を生じさせる。転移学習と、多くの最先端モデルが公開されていることにより、テクノロジー企業は公開モデルを基に自社のモデルを構築することが増えており、そのことが、使用されているモデルの構造や種類について自由にアクセスできる情報を攻撃者に与えている。

メンバーシップ推論とモデル反転も、敵対的機械学習における具体的な攻撃の種類として挙げられている。

## OWASP Top 10 for LLM Applications において

[[DefinedTermSet/owasp-top-10-for-llm-applications|OWASP Top 10 for LLM Applications]] のバージョン 1.1（2023年）は、モデル抽出を項目 LLM10「モデルの窃取（Model Theft）」の中で扱っている。この項目はより広く、侵害されたモデルリポジトリ、内部者による漏洩、サプライチェーンの不備など、あらゆる手段による独自 LLM への不正アクセスとその持ち出しを対象とする。また、このリストは「モデル抽出」を上記より狭い意味で用いている。すなわち、学習データを復元することではなく、モデルの出力からモデルを複製することである。

| 手法 | リストによる説明 |
| --- | --- |
| クエリベースのモデル抽出 | 攻撃者が、特定のトピックについて慎重に作り込んだ大量のプロンプトでモデルの API に問い合わせ、別のモデルをシャドウモデルとしてファインチューニングするのに十分な出力を収集する |
| 機能的なモデル複製 | 標的モデルにプロンプトを与えて合成学習データを生成させ（「self-instruct」と呼ばれる手法）、それを用いて別の基盤モデルをファインチューニングし、機能的に同等なものにする。これはクエリベースの抽出の限界を回避する。研究ではある LLM を別の LLM で学習させるために使われてきたが、そこでは攻撃ではなかった。しかし攻撃者は、公開 API を持つ独自モデルを複製するためにこれを利用しうる |
| サイドチャネル攻撃 | 攻撃者が LLM の入力フィルタリングを回避し、モデルの重みとアーキテクチャの情報を自らの管理下にあるリソースへ収集する |

リストによれば、クエリベースの抽出には限界がある。プロンプトが十分に具体的でなければ出力は役に立たず、出力にはハルシネーションによる回答が含まれうる。また、この方法では LLM を完全に複製することはできず、部分的にしか複製できない。窃取されたモデルは、さらなる攻撃を準備するためのシャドウモデルとして使われうる。たとえば、モデルに含まれる機微な情報に到達したり、高度なプロンプトインジェクションを準備するために敵対的入力を検知されずに試したりする攻撃である。

## 防御

機械学習を保護するために研究者が提案してきた手段の一つに、モデル窃取への対策として、攻撃者が受け取る情報を改変する情報ロンダリング（information laundering）がある。

OWASP のリストが挙げるモデル窃取への対策には、モデルリポジトリと学習環境に対する強力なアクセス制御（ロールベースのアクセス制御や最小権限など）と認証、LLM によるネットワークリソース、内部サービス、API へのアクセスの制限、アクセスログの監視と監査、そして MLOps のデプロイにおける追跡と承認ワークフローを伴うガバナンスが含まれる。また、データの持ち出しのリスクを減らすための API 呼び出しのレート制限やフィルター、抽出活動を検知するためのデータ損失防止（DLP）などの技術、抽出クエリの検知に役立つ敵対的ロバストネス訓練、そして LLM のライフサイクルの埋め込み段階と検知段階における電子透かしの枠組みも推奨している。
