敵対的機械学習とは、[機械学習](https://en.wikipedia.org/wiki/Machine_learning)アルゴリズムに対する攻撃と、それに対する防御の研究である。機械学習の手法の多くは、訓練データとテストデータが同じ統計分布に由来するという前提で設計されている。しかし、利害の大きい実際の応用ではこの前提がしばしば破られる。ユーザーがこの前提を崩す捏造データを意図的に与えることがあるからである。

## 主な攻撃の種類

最も一般的な攻撃は、回避攻撃、データポイズニング攻撃、ビザンチン攻撃、モデル抽出である。

| 攻撃 | 敵対者が行うこと |
| --- | --- |
| [[DefinedTerm/evasion-attack\|回避]] | 訓練データに影響を与えることなく、訓練済みモデルへの入力を改変して正当なものとして分類させる |
| [[DefinedTerm/data-poisoning\|データポイズニング]] | 出力の誤りを増やすよう設計されたデータで訓練データセットを汚染する |
| ビザンチン攻撃 | 分散学習や[連合学習](https://en.wikipedia.org/wiki/Federated_learning)において、参加デバイスの一部が期待される振る舞いから逸脱する。たとえば中央サーバーのモデルを損なったり、特定の振る舞いに偏らせたりする |
| [[DefinedTerm/model-extraction\|モデル抽出]] | ブラックボックスのシステムを探って、その訓練に使われたデータを抽出する。極端な場合であるモデル窃取（model stealing）では、モデルを完全に再構築できるほどの情報が抽出される |

教師あり学習アルゴリズムに対する攻撃は、次の3つの軸に沿って分類されてきた。

- **分類器への影響** — 攻撃が分類フェーズを妨害するかどうか。脆弱性を見つけるための探索フェーズが先行する場合もある。
- **セキュリティ侵害** — 悪意あるデータを正当なものとして分類されるよう与えるのか、それとも訓練時に与えて後に正当なデータが拒否されるようにするのか。
- **特異性** — 標的型攻撃として特定の侵入や妨害を狙うのか、無差別型攻撃として全般的な混乱を引き起こすのか。

この分類法はその後、敵対者の目的、攻撃対象システムについての知識、入力やシステム構成要素を操作する能力、攻撃戦略を含む、より完全な脅威モデルへと拡張され、さらに防御戦略の次元も加えて拡張された。

従来型のモデル（サポートベクターマシンや線形回帰など）だけでなく深層学習システムにも有効な特定の攻撃類型として、[[DefinedTerm/adversarial-example|敵対的サンプル]]、トロイの木馬攻撃やバックドア攻撃、モデル反転、メンバーシップ推論がある。

## 歴史

- **2004年** — 1月の MIT スパム会議で、John Graham-Cumming は、スパムメールが非スパムと分類されるにはどの単語を加えればよいかを自動的に学習させることで、ある機械学習スパムフィルタを使って別のスパムフィルタを打ち破れることを示した。同年、Nilesh Dalvi らは、スパムフィルタで使われる線形分類器が、スパマーが「良い単語」を挿入するという単純な回避攻撃で打ち破られうることを指摘した。
- **2006年** — Marco Barreno らが攻撃の広範な分類法を示した。
- **2012〜2013年** — 多くの研究者は、サポートベクターマシンやニューラルネットワークのような非線形分類器なら敵対者に対して頑健かもしれないと依然として期待していたが、Battista Biggio らがそうしたモデルに対する最初の勾配ベースの攻撃を実証した。
- **2014年以降** — Christian Szegedy らが、やはり勾配ベースの攻撃で敵対的摂動を作り出し、深層ニューラルネットワークが敵対者によって欺かれうることを実証した。

その後の研究で、敵対的攻撃は制御されていない環境では生み出すのが難しくなることが示された。そうした環境では環境上の制約が加えたノイズの効果を打ち消しうるからである。わずかな回転や照明のわずかな変化で、敵対的画像の効果が失われることがある。Google Brain の Nick Frosst は、自動運転車に一時停止標識を見落とさせるには、敵対的サンプルを作るよりも標識を物理的に取り除くほうがはるかに簡単だと指摘している。また彼は、この分野が、ある分布のデータで訓練されたモデルがまったく異なる分布でもうまく機能すると誤って想定していると考えている。

この分野は依然として学術界に深く根ざしているが、Google、Microsoft、IBM といった大手テクノロジー企業は、他者が機械学習モデルの頑健性を評価し敵対的攻撃のリスクを減らせるよう、ドキュメントやオープンソースのコードベースの整備を始めている。

## 応用される領域

この分野の例として次のものが挙げられている。

- **スパムフィルタリング** — 「悪い」単語の綴りを崩したり「良い」単語を挿入したりしてスパムを難読化する。
- **コンピュータセキュリティ** — マルウェアのコードをネットワークパケット内に難読化して隠したり、ネットワークフローの特徴を改変したりして[[DefinedTerm/intrusion-detection-system|侵入検知]]を誤らせる。
- **生体認証** — 偽の生体的特徴を用いて正当なユーザーになりすましたり、ユーザーの特徴に時間をかけて適応するテンプレートギャラリーを侵害したりする。
- **マルウェア検知** — 研究者らは、悪意ある機能を保ったまま学習ベースの検知器を回避するバイナリを自動的に作り出す手法を提案している。たとえば、遺伝的アルゴリズムを用いて Windows 実行ファイルに無害なコンテンツを注入する GAMMA や、敵対的生成ネットワークを用いてマルウェアが無害と分類されるような摂動を学習する Mal-LSGAN がある。
- **人間の行動認識** — 攻撃者が人間の特徴の表現にノイズを加え、監視、自動運転車、屋内モニタリングに使われる認識システムを欺く。

## セキュリティに機械学習を用いる際の課題

研究者らは、セキュリティ領域の機械学習が一般的なベンチマーク領域とは異なる制約の下で機能することを指摘している。セキュリティデータは時間とともに変化したり、誤ってラベル付けされたサンプルを含んだり、敵対的な振る舞いを反映したりすることがあり、それが評価と再現性を難しくする。

| 課題 | 出典の記述内容 |
| --- | --- |
| データ収集 | バイナリ、ネットワークトレース、ログを特徴量に変換する際にバイアスが入り込むことがある。関連するマルウェアサンプルが訓練用とテスト用の分割をまたいで分離されていないと、時間に基づくリークが生じ、過度に楽観的な結果につながる |
| ラベルと正解データ | アンチウイルスエンジンが同じサンプルを互いに矛盾する形で分類することがあり、マルウェアファミリーは時間とともに改名・再編されることがある |
| コンセプトドリフト | マルウェア作成者は適応を続けるため、悪意あるサンプルの統計的性質が変化し、システムを更新するか逐次学習させない限りモデルの性能が低下しうる |
| 特徴量の頑健性 | ヘッダーフィールドのような単純な静的属性は攻撃者が容易に改変できる。制御フローグラフのような構造的特徴量はより安定しているが、抽出のコストが高い |
| クラス不均衡 | 悪意あるサンプルは実データの0.01%〜2%にすぎないことがあり、モデルが多数派クラスに偏る。Android のアクティビティ系列で事前学習済み BERT モデルをファインチューニングしたある研究は、マルウェアが0.5%のデータセットで F1 スコア0.919を報告しており、LSTM や n-gram モデルを上回った |
| システム設計 | データスヌーピング（現実世界では利用できない情報を用いた訓練）、悪意ある振る舞いではなくコンパイラの痕跡を学習するといった見せかけの相関、テストセットでのハイパーパラメータ調整 |
| 評価 | 不適切なベースラインと評価指標（偽陽性率が決定的に重要な侵入検知システムでは、正解率だけを報告するのは不十分だとしばしば指摘される）と、基準率の誤謬 |
| 展開 | 静的な実験室環境でのみ評価すること、そして ML システムそのものを攻撃対象領域として扱わない脅威モデル |

## 防御

研究者らは、機械学習を保護するための多段階のアプローチを提案している。脅威モデリング（攻撃者の目的と能力の形式化）、攻撃シミュレーション、攻撃の影響評価、対策の設計、回避ベースの攻撃に対するノイズ検出、そしてモデル窃取に対する情報ロンダリング（敵対者が受け取る情報を改変すること）である。

回避攻撃、ポイズニング攻撃、プライバシー攻撃に対して提案されている防御機構には、セキュアな学習アルゴリズム、ビザンチン耐性アルゴリズム、複数分類器システム、プライバシー保護学習、ゲーム理論モデル、訓練データのサニタイズ、敵対的訓練、バックドア検出アルゴリズム、ムービングターゲット防御がある。出典では、そのうち2つの系統に但し書きが付いている。

- **勾配マスキングや勾配の難読化**は、ホワイトボックス攻撃において敵対者が勾配を悪用するのを防ごうとするものだが、信頼できないとみなされている。そうしたモデルはブラックボックス攻撃に対して依然として脆弱であるか、別の方法で回避されうるからである。
- **モデルのアンサンブル**は、回避攻撃には効果がないが、データポイズニング攻撃には効果があることが示されている。

## 混同しやすい概念

敵対的機械学習は、敵対的生成ネットワークや競合学習とは別のものである。
