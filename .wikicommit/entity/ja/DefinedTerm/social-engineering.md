情報セキュリティにおいて、ソーシャルエンジニアリングとは、心理的な圧力を用いて人に行動を起こさせたり機密情報を漏らさせたりすることである。より広く「本人の最善の利益になるかどうかにかかわらず、人にある行動をとらせるよう影響を与えるあらゆる行為」とも定義されている。情報収集、詐欺、システムへのアクセスに用いられる信用詐欺の一種であり、より複雑な詐欺計画の多くの段階のうちの一つであることが多いという点で、従来の「詐欺（con）」とは異なる。[[DefinedTerm/phishing|フィッシング]]はソーシャルエンジニアリングの一種である。

ソーシャルエンジニアリングは心理的操作の一形態であり、その手法は認知バイアスとして知られる人間の意思決定の弱点に依拠している。2019年と2020年には、研究者がこれを組織や国家にとってますます重要になっている課題と表現しており、報告によれば、ソーシャルエンジニアリング攻撃は2024年にかけて激しさと件数の両面で増加していた。

## 例

二つの単純な例がこれを示している。一つ目では、攻撃者が会社の建物内に、ヘルプデスクの電話番号が変わったという公式に見える掲示を出す。偽の番号に電話をかけた従業員は、パスワードと ID を尋ねられる。二つ目では、攻撃者がソーシャルネットワーキングサイト上で標的と会話を始め、徐々に信頼を得て、その信頼を利用してパスワードや銀行口座の詳細などの機密情報を手に入れる。

## 手法

| 手法 | 内容 |
| --- | --- |
| プリテキスティング（英国では「blagging」） | 作り上げたシナリオ（口実＝プリテキスト）を作って用い、被害者に情報を漏らさせたり、普段ならしない行動をとらせたりする。通常は、正当に見せかけるための事前調査となりすましを伴う |
| 水飲み場型攻撃（water holing） | ユーザーが日常的に訪れるウェブサイトに寄せる信頼を悪用する標的型の戦略。ユーザーはそうしたサイトでは、リンクをたどるなど、他の場所では避けるような行動をとる。非常に安全とされるシステムへのアクセスを得るために使われたことがある |
| ベイティング | 現実世界のトロイの木馬。好奇心をそそるラベルを付けた、マルウェアに感染した USB ドライブなどの物理メディアを、人が見つける場所に置いておき、被害者の好奇心や欲に付け込む |
| 広告フィッシング | 銀行、ソフトウェア提供者、カスタマーサポートのページなど、信頼された主体を模倣したオンライン広告を用いて、パスワード、カード情報、その他のデータを盗む詐欺サイトへユーザーを誘導する（Google による説明） |
| クイド・プロ・クオ（見返り） | 便宜と引き換えに情報や金銭を提供する。たとえば、無料の IT サポートを申し出る専門家を装い、ユーザーのログイン認証情報を求める |
| スケアウェア | 偽の脅威についてのメッセージを被害者に浴びせ、システムが感染していると思い込ませたうえで、悪意あるソフトウェアのインストールを促したり、身代金を脅し取ったりする |
| テールゲーティング（ピギーバッキング） | 従業員やその他のアクセス権を持つ人物を装い、オフィスや立入制限区域に入る |

2016年にイリノイ大学で行われた研究は、ベイティングの例を示している。研究者たちは、研究者が所有するウェブページにリンクするファイルを入れた USB ドライブ 297 個をキャンパス中に落としておいた。そのうち 290 個（98%）が拾われ、135 個（45%）が「発信（call home）」した。

## 米国の法律

米国の連邦法は、二つの分野でプリテキスティングを扱っている。

- **銀行記録。** 1999年のグラム・リーチ・ブライリー法は、銀行記録のプリテキスティングを、連邦法の下で処罰される違法行為としている。虚偽の口実によって金融機関や消費者から個人の非公開情報を入手することはすべてこれに該当し、私立探偵などの事業体による欺瞞は連邦取引委員会の管轄に属する。
- **電話記録。** 2006年電話記録・プライバシー保護法（Telephone Records and Privacy Protection Act of 2006）は、2006年12月に議会で承認され、2007年1月12日にジョージ・W・ブッシュ大統領が署名したもので、電話記録のプリテキスティングを連邦の重罪とした。罰則は個人に対しては最高 25万ドルの罰金と 10年の禁錮、企業に対しては最高 50万ドルの罰金である。この法律は、少なくとも部分的には、ヒューレット・パッカードのスパイ・スキャンダルを受けて可決された。このスキャンダルでは、同社の取締役会が雇った私立探偵会社が、プリテキスティングによって取締役やジャーナリストの電話記録を入手していた。

## 主な事件

| 年 | 事件 | 用いられたソーシャルエンジニアリング |
| --- | --- | --- |
| 1970年代後半〜1980年代前半 | ロサンゼルスでのフリーキングとコンピュータハッキング | 電話とコンピュータのハッキングにおけるソーシャルエンジニアリング |
| 1990年代 | 生まれつき全盲の3兄弟によるイスラエルでの電話・コンピュータ詐欺 | ソーシャルエンジニアリングと声のなりすまし |
| 2011年 | RSA SecurID への攻撃 | 採用サイトを名乗る送信元から4人の従業員にメールが送られ、ゼロデイエクスプロイトを仕込んだスプレッドシートが添付されていた。SecurID の二要素認証トークンについて得られたデータは、後に防衛関連企業ロッキード・マーティンへの攻撃の試みに使われた |
| 2013年 | 米国労働省の水飲み場型攻撃 | 侵害された労働省のサーバーがマルウェアをホストし、一部の訪問者をリモートアクセス型トロイの木馬をインストールするサイトへリダイレクトした。標的は機密性の高い核関連データにアクセスできる職員だったとみられる |
| 2014年 | ソニー・ピクチャーズの情報流出 | 上級社員を装ったフィッシング攻撃者がマルウェアをインストールした。北朝鮮と関係しているとみられる「Guardians of Peace」グループが機密データを流出させた |
| 2015年 | Ubiquiti Networks の詐欺 | 香港支社から送られたように見えるフィッシングメールが経理部門に送られ、支払い情報の変更を求めた。同社は約 4,700万ドルを失い、800万ドルを回収した |
| 2016年 | 米国大統領選挙をめぐる流出 | ロシア軍の情報機関（GRU）に関係するハッカーが、Google のアラートを装ったフィッシングメールを大統領選挙陣営のメンバーに送り、その後メンバーのパスワード、メール、文書が流出した |
| 2017年 | Equifax の侵害に関するヘルプサイト | Equifax の侵害の後、正規のヘルプサイトのアドレスにわずかな変化を加えた悪意あるドメイン 194 個が1日以内に登録され、入力ミスに付け込んだ |
| 2017年 | Google と Facebook に対する請求書詐欺 | 詐欺師がハードウェア供給業者になりすまし、2年間にわたって両社に 1億ドルの虚偽の請求を行った。この資金は、米国司法省の措置の後に回収された |

## 対策

研究者たちはソーシャルエンジニアリングに対する検知手法やサイバーセキュリティ教育プログラムを開発しており、いくつかの事業者がソーシャルエンジニアリングに関する研修や教育を提供している。その中には、2000年代に開発された、認定ソーシャルエンジニアリング防止スペシャリストのためのプログラムも含まれる。
