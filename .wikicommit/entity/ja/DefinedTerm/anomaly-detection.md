データ分析において、異常検知（外れ値検出とも呼ばれ、ときに新規性検出とも呼ばれる）とは、一般に、データの大多数から大きく外れ、明確に定義された正常な振る舞いの概念に合致しない、まれな項目・事象・観測を特定することと理解されている。そうした観測は、異なるメカニズムによって生成されたのではないかという疑いを抱かせたり、データの残りの部分と整合しないように見えたりすることがある。異常検知は教師なし機械学習の重要な下位分野であり、その応用にはサイバーセキュリティや[[DefinedTerm/intrusion-detection-system|侵入検知]]が含まれる。

## 何が異常とみなされるか

あらゆる領域に当てはまる異常検知の単一の操作的定義は存在しない。何が「正常」かは、データ、観測の表現方法、観測が生じる文脈、そして検知手法の前提に依存するからである。異常は必ずしもデータの誤りではない。応用によっては、計測や記録の誤り、データを生成したプロセスの変化、珍しいが妥当な観測、あるいは不正、機器の故障、セキュリティ侵入といった注目すべき事象である場合がある。また、異常はまれさや他の観測からの距離だけで定義されるわけでもない。手法によって、正常性を確率分布、距離や局所密度、クラスタへの所属、正常データを囲む境界、予測誤差、再構成誤差、その他のモデル固有の基準によって特徴づける。

多くの手法は、即座にラベルを返すのではなく、数値の**異常スコア**を返す。このスコアは、観測が当てはめた正常性のモデルからどれだけ外れているかを表し、判定しきい値によって二値の判定に変換される。したがって、ある観測が異常とラベル付けされるかどうかは、正常性のモデル、利用可能な文脈、判定ルールに依存する。

異常はもともと、統計分析（たとえば平均や標準偏差の算出）を助け、モデルによる予測を改善するために、データから除外または省略する目的で探されていた。しかし多くの応用では、異常そのものが最も関心の高い観測であり、ノイズや無関係な外れ値から切り分ける必要がある。

## 異常の種類

広く用いられている分類では、次の3種類を区別する。

| 種類 | 内容 | 出典が挙げる例 |
| --- | --- | --- |
| 点異常 | データの残りの部分に対して異常である個々の観測 | データセット内の他の取引と比べて異常に大きい取引 |
| 文脈的（条件付き）異常 | 時間的、空間的、人口統計的、あるいは応用によって定義される特定の文脈の中でのみ異常となる観測 | 夏には正常だが冬には異常な気温 |
| 集団的異常 | 個々の観測は異常でなくても、全体として異常である関連した観測の集まり | 時系列中の異常な部分系列や、コンピュータネットワークにおける予期しない活動パターン |

独立した観測には点異常の手法で足りる場合があるが、時系列、空間データ、系列、グラフでは、文脈的または集団的な関係を明示的にモデル化する必要があることが多い。

## 利用可能なラベルによるアプローチ

| アプローチ | 前提 |
| --- | --- |
| 教師あり | 「正常」と「異常」のラベルが付いたデータセットを用いて分類器を訓練する。ラベル付きデータが一般に入手できず、クラスが本質的に不均衡であるため、めったに使われない |
| 半教師あり | データの一部にラベルが付いている。多くの場合、正常な訓練データから正常な振る舞いのモデルを構築し、テストインスタンスがそのモデルによって生成された尤度を検定する |
| 教師なし | データにラベルが付いていない。圧倒的に最もよく使われるアプローチ |

## 手法

多くの手法が提案されている。その性能は通常データセットに依存し（局所的な外れ値に向くものもあれば、大域的な外れ値に向くものもある）、多数のデータセットで比較すると、手法間に体系的な優劣はほとんどない。ほぼすべての手法で、性能に決定的な影響を与えながら通常は適用前には分からない、直感的でないパラメータの設定が必要である。出典は代表的な手法を次のように分類している。

| カテゴリ | 出典が挙げる例 |
| --- | --- |
| 統計的・ノンパラメトリック | ヒストグラムベース（頻度ベースまたは計数ベース）のスコアリング、正常データの分布を近似するカーネル関数 |
| 統計的・パラメトリック | Zスコア、Tukey の範囲検定、Grubbs 検定 |
| 密度ベース | k近傍法、局所外れ値因子法（LOF）、Isolation Forest、高次元データ向けの部分空間ベース・相関ベース・テンソルベースの外れ値検出、One-Class サポートベクターマシン |
| ニューラルネットワークと関連モデル | レプリケーターニューラルネットワーク、オートエンコーダと変分オートエンコーダ、長短期記憶（LSTM）ネットワーク、ベイジアンネットワーク、隠れマルコフモデル、最小共分散行列式、そして畳み込みニューラルネットワーク（画像・映像データ向け）、Simple Recurrent Unit（時系列向け）、適応させた基盤モデルを含む深層学習 |
| クラスタベース | クラスタ分析に基づく外れ値検出、相関ルールや頻出アイテム集合からの逸脱、ファジィ論理に基づく検知 |
| アンサンブル | 特徴量バギング、スコアの正規化、さまざまな多様性の源 |
| 量子 | 近未来の量子ハードウェア上で研究されている量子サポートベクターマシンと正規化フロー |
| その他 | 高速な予測のために特徴量の独立性を仮定する Histogram-based Outlier Score（HBOS） |

多くの手法はスコアしか出さないため、説明可能な異常検知はより詳しい説明を求める。Subspace Outlier Degree はサンプルがどの属性で逸脱しているかを特定し、Correlation Outlier Probabilities はサンプルが期待される位置からどのように逸脱しているかを計算する。後者は反実仮想的な説明として読むことができる。

金融システム、ソーシャルメディア上の相互作用、交通インフラなどを表す動的ネットワークにおける異常検知では、関係や状態が変化し続けるため、適応的な手法が必要になる。出典は、そこで見られる異常の種類として、コミュニティ異常、圧縮異常、分解異常、距離異常、確率モデル異常を挙げている。

## セキュリティにおける利用

異常検知は1986年に Dorothy Denning によって侵入検知システム向けに提案された。侵入検知のための異常検知は通常しきい値と統計によって行われるが、ソフトコンピューティングや帰納的学習を用いることもできる。1999年までに提案された特徴量には、頻度、平均、分散、共分散、標準偏差に基づく、ユーザー、ワークステーション、ネットワーク、リモートホスト、ユーザーグループ、プログラムのプロファイルが含まれていた。侵入検知におけるその対になるものは不正使用検知（misuse detection）である。

出典は侵入検知の歴史を次のようにたどっている。システム管理者による手作業の監視から始まり、1970年代後半から1980年代前半の監査ログやシステムログの事後分析を経て、1990年代には生成されると同時に監査データを分析するリアルタイムの侵入検知システムが登場し、その後、より大規模で複雑なネットワーク向けの手法の研究が行われた。

出典が説明するその他のセキュリティ関連の応用には次のものがある。

- **不正検知** — 異常検知はフィンテックにおける不正防止に不可欠だとされている。
- **映像監視** — 畳み込みニューラルネットワークと Simple Recurrent Unit を用いた深層学習の手法は、映像中の異常な活動の特定において有望な成果を示しており、多数のストリームを少ない計算資源で処理するには、スケーラブルなリアルタイムのフレームワークが必要とされる。
- **ITインフラストラクチャ** — 検知された異常は、性能低下やシステム障害を特定し、未然に防ぐのに役立つ。
- **IoTシステム** — 異常検知は、モノのインターネット（IoT）機器のネットワークにおけるシステム障害やセキュリティ侵害の特定に役立つ。出典が引用するある多段階のフレームワークは、空間クラスタリング、密度ベースのクラスタリング、局所性鋭敏型ハッシュを組み合わせている。

セキュリティ以外では、出典は、故障検知、システムのヘルスモニタリング、センサーネットワークにおける事象検知、生態系の撹乱、マシンビジョンにおける欠陥検出、医療診断、法執行、石油産業および石油・ガス産業における機械やパイプラインの監視を挙げている。異常の除去は前処理の一段階でもある。除去後には平均や標準偏差といった統計量がより正確になり、教師あり学習では精度が統計的に有意に向上することが多い。

## 関連用語

異常（anomaly）、外れ値（outlier）、新規性（novelty）という用語は互換的に使われることもあるが、用法は統計学、機械学習、信号処理、応用領域によって異なり、その区別は一貫して適用されているわけではない。*外れ値*は一般に、データセットの残りの部分と整合しないように見える観測を指し、外れ値検出の手法では、モデルの当てはめに使うデータの中にそうした観測が含まれていることを許容する場合が多い。*新規性検出*では、訓練データは一般に正常な振る舞いを表すと仮定され、これまでに見られなかった観測がそのモデルに照らして評価されるため、1クラス分類として定式化されることが多い。より広い用語である異常検知は、これらすべての設定を包含するものとしてよく使われる。

## ソフトウェアとデータセット

出典が挙げるオープンソースのツールには、Java のデータマイニングツールキット ELKI、異常検知専用に開発された Python ライブラリ PyOD、scikit-learn がある。Wolfram Mathematica も教師なしの異常検知を提供している。公開されているベンチマーク集には、ルートヴィヒ・マクシミリアン大学ミュンヘンの Anomaly detection benchmark data repository、ODDS、Harvard Dataverse の Unsupervised Anomaly Detection Benchmark、そして正解データ付きの12,000を超えるデータセットを収める Research Data Australia の KMASH Data Repository がある。
