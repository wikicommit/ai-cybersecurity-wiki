フィッシングとは、攻撃者が人々をだまして機微な情報を明かさせたり、マルウェアをインストールさせたりする、ソーシャルエンジニアリングの一形態であり、詐欺である。認証情報の窃取、セッションハイジャック、マルウェアの配布、コマンドの実行に用いられることがあり、一部の攻撃は認証を正規のサイトへ透過的に中継して、攻撃者が認証情報と認証済みセッションの両方を手に入れる。フィッシングは一般的な初期アクセスの手法であり、大規模言語モデルはパーソナライズされたフィッシングを低コストで自動化できる。

フィッシング攻撃は電子メールで届けられることが多く、人々をだまして機微な情報やログイン認証情報を渡させようとする。典型的には、銀行や政府機関のような信頼できる送信元から来たように見えるメッセージを用い、偽造のログインページへリダイレクトすることもある。よくある標的には、金融機関、電子メールやクラウドの生産性ツールの提供者、ストリーミングサービスが含まれる。盗まれた情報やアクセスは、金銭の窃取、マルウェアのインストール、標的組織内の他者へのスピアフィッシングに使われることがあり、侵害されたストリーミングアカウントはダークネットマーケットで販売されることがある。

## 形態

一般的なフィッシングは広く送りつけられるのに対し、スピアフィッシングは特定の人物や集団を標的とする。

| 形態 | 経路または仕組み | 出典による補足 |
| --- | --- | --- |
| スピアフィッシング | 個人や組織の情報を用いて信憑性を高めた、特定の個人に合わせたメッセージ | 一般的なフィッシングより効果的な場合がある。自動化によって、パーソナライズされたメッセージを大規模に用いられるほど安価にできる |
| ホエーリング | 上級指導者の役職にある人々を狙ったスピアフィッシング | 価値の高い組織の情報を狙う |
| ボイスフィッシング（ビッシング） | 電話や Voice over IP の通話。自動化されていることもあり、音声合成や偽装された発信者番号を用いる | 2008年の研究は、これが電子メールよりも音声通話に対して人々が抱く高い信頼を悪用しうることを明らかにした |
| SMS フィッシング（スミッシング） | なりすまし、悪意のあるリンク、マルウェアのおとりを含む SMS や MMS のメッセージ | モバイル端末では URL の表示が限られるため、不正なリンクを見抜きにくい。2024年、米国の人々はテキストメッセージ詐欺による4億7,000万米ドルの損失を連邦取引委員会に報告しており、最も多かったのは偽の荷物配達メッセージだった |
| QR コードフィッシング（クィッシング） | 読み取った人を悪意のあるウェブサイトへ送る QR コード | コードは行き先を隠す。1,876人の参加者による3つの実験を通じて、QR コードを用いたフィッシングを見抜いた人はほとんどいなかった。英国の National Cyber Security Centre は、これを他の種類のサイバー詐欺より少ないと評価している |
| 中間者型（AiTM）フィッシング | 偽サイトが認証のやり取りをリアルタイムで正規のサービスへ中継する | ユーザーが入力するワンタイムコードに依存する認証を破る。Evilginx のようなツールキットがこれを自動化し、被害者がフィッシングサイトを操作している間に認証情報と二要素認証のコードを中継する |

## 手口

- **ソーシャルエンジニアリング。** フィッシングは典型的には信頼できる主体になりすまし、たとえば銀行口座や保険の契約を解約または差し押さえると脅すなどして切迫感を作り出し、被害者にリンクをクリックさせたり、添付ファイルを開かせたり、情報を明かさせたり、偽装されたウェブサイトで認証情報を入力させたりする。
- **リンクの操作。** リンクには、綴りを誤った登録ドメインや紛らわしいサブドメイン（`example.com.scam.com` は `scam.com` に属する）が使われることがある。また、フィッシング実行者のサイトへのリンクの上に信頼できそうなテキストを表示したり、IDN スプーフィングやホモグラフ攻撃によって国際化ドメイン名を悪用したり、信頼できるウェブサイト上のオープンリダイレクタを経由したりすることもある。
- **ドライブバイ侵害との組み合わせ。** MITRE ATT&CK はフィッシングとドライブバイ侵害を別々の初期アクセス手法として分類しているが、フィッシングのメッセージがドライブバイ侵害に使われるウェブサイトへリンクすることがあるため、両者は同じキャンペーンの中で起こりうる。
- **フィッシング・アズ・ア・サービス。** プラットフォームが、ログインページを複製し、テンプレート化された基盤を通じてリンクを配布することで、ブランドを装ったフィッシングキットを自動化し、キャンペーンの実行に必要なスキルを引き下げている。ENISA は、Darcula プラットフォームが200を超える組織になりすまし、100を超える国のユーザーを標的にしていたと報告した。

## 生成 AI とフィッシング

生成 AI は、現実味のあるテキストや画像を生成することで、フィッシングやその他のソーシャルエンジニアリングのコンテンツをより説得力のあるものにでき、攻撃のパーソナライズや自動化に必要な労力を減らすことができる。7,700人の参加者による2026年の実験では、大規模言語モデルがパーソナライズした電子メールは、汎用的なフィッシングメールのほぼ3倍のクリック率を生み、その推定コストは1通あたり約0.03米ドルだった。

## 規模と歴史

AOL のアカウント情報を狙うフィッシング攻撃は1995年に報告されており、この用語は1997年3月までに活字に現れた。その綴りは一般に、それ以前からあった「フリーキング（phreaking）」という用語と結びつけられている。2000年代には攻撃がより組織的かつ標的型になり、フィッシングはブラックマーケットの完全に組織化された一部として認識されるようになった。専門家がフィッシングソフトウェアを販売し、組織的な集団がそれを組み合わせてキャンペーンを行った。以降の注目すべき攻撃には、2011年の RSA SecurID トークンに関する情報の窃取、2013年にフィッシングされた下請け業者のアカウントを通じて Target から1億1,000万件の顧客およびカードの記録が盗まれた事件、そして出典がロシアの集団 Fancy Bear と結びつけているスピアフィッシングキャンペーン（2016年の民主党全国委員会に対するものを含む）がある。2020年7月の Twitter への侵入は、偽造の社内サービスのログインページと電話によるソーシャルエンジニアリングを組み合わせたものだった。

| 指標 | 数値 |
| --- | --- |
| 米国での損失、2004年5月〜2005年5月 | 約120万人のユーザー、約9億2,900万米ドル |
| 2007年の損失 | 360万人の成人が32億米ドルを失った |
| FBI インターネット犯罪苦情センター、2025年 | フィッシングおよびスプーフィングの区分で191,561件の苦情、報告された損失は約2億1,580万米ドル |
| 欧州の脅威状況における4,875件のインシデントの分析、2024年7月〜2025年6月 | 観測された初期アクセスの事例の約60%をフィッシングが占めた |

## 防御

フィッシング対策のプログラムは、単一のフィルターや認証手順に頼るのではなく、重なり合う統制を用いて、トレーニング、メール、ブラウザ、ネットワーク、認証、インシデント対応の各層の対策を組み合わせる。

| 層 | 対策 | 示されている限界 |
| --- | --- | --- |
| ユーザートレーニング | 受信者がテストメッセージに反応した後に教材を表示する、フィッシングの模擬演習 | ある企業での2024年の実地研究によれば、測定された効果は主に演習が生む定期的な注意喚起によるもので、クリック後に表示される教材によるものではなかった。従業員はその教材をしばしば読まず、受講の義務化も安全な行動を改善しなかった |
| メールのフィルタリングと送信者認証 | コンテンツと評判に基づくフィルタリング。ドメインレベルの認証のための SPF と DKIM。表示される `From` ドメインとの整合を確認し、処理と報告のポリシーを公開するための DMARC | DMARC は表示名、類似ドメイン、内容を検証せず、合格してもメッセージが安全になるわけではない。2021年の実験では、試験した30のメールサービスと23の電子メールクライアントのすべてが、新たに特定された送信者なりすまし手法の少なくとも1つに対して脆弱だった |
| ブラウザとネットワークでのブロック | フィッシング対策のブロックリストに載った宛先に対するブラウザの警告（ヒューリスティックな分類器を伴うこともある）。フィッシングの脅威フィードにあるドメインの名前解決を拒否する保護 DNS | 事後対応的である。新しいサイトがリストに載るまでに空白期間が生じうるうえ、回避的なサイトは迅速な分類を免れることがある |
| フィッシング耐性のある認証 | 多要素認証。暗号学的な応答を依拠当事者のドメインに結びつける WebAuthn と、パスキー（同期可能な WebAuthn 認証器） | NIST は、手入力するワンタイムパスワードや帯域外のコードをフィッシング耐性があるものとは分類していない。なりすまし者がそれらを中継できるためである |
| セッションの保護 | ID トークンとアクセストークンの短く定められた有効期間、失効と利用対象の制限、セッションの監視、そして可能な場合には送信者制約付きトークンや所有証明トークン（NIST の推奨） | 中間者型プロキシによって奪われたセッション Cookie は、期限切れになるか無効化されるまでベアラーシークレットとして機能するため、必要となる |
| 検知、報告、テイクダウン | ユーザーからの報告と自動検知がブロックリストに反映される。運営者はホスティング事業者やレジストラに基盤の停止を依頼する | テイクダウンは協力に依存し、数時間から数日かかることがある |

## 法的対応

フィッシングは通常、単一の犯罪としてではなく、関係する行為を対象とする法律の下で訴追される。米国では、コンピュータ詐欺・不正利用防止法（Computer Fraud and Abuse Act）が特定の形態の不正なコンピュータアクセスを対象とし、通信詐欺、アクセスデバイス詐欺、加重的な個人情報窃盗には他の連邦規定が適用されることがある。欧州連合では、指令（EU）2019/713 が加盟国に対し、非現金決済手段に関わる特定の行為を犯罪とするよう義務づけており、その前文はフィッシングをそれらを入手する方法の一つとして挙げている。イングランドとウェールズの訴追指針は、フィッシングを、2006年詐欺法、1990年コンピュータ不正使用法および関連法の下でのサイバー技術を利用した詐欺として扱っている。キャンペーンは国境を越えるため、執行はブダペスト条約のような国際協力にも依存している。2026年9月20日時点で、国連サイバー犯罪条約の署名国は82、締約国は3であり、まだ発効していなかった。
