ジェイルブレイクプロンプトとは、大規模言語モデル（LLM）に組み込まれたセーフガードを回避し、そのベンダーが定めた利用ポリシーに違反する有害なコンテンツをモデルに生成させるよう意図的に設計された敵対的プロンプトである。ジェイルブレイクプロンプトを用いると、LLM は、プロンプトがなければ適切に拒否するはずの危険な質問に対して詳細な回答を与えることがある。ここでいうプロンプトとは、特定の種類のコンテンツを生成させるために LLM に与えられる最初の入力または指示のことであり、ジェイルブレイクプロンプトは、ユーザーがオンラインで共有する有益なプロンプトの悪意ある対応物である。測定研究 [[ScholarlyArticle/do-anything-now-characterizing-and-evaluating-in-the-wild-jailbreak-prompts-on-large-language-models]] は、これを LLM のセーフガードを回避するための主要な攻撃ベクトルと呼んでいる。

## 出どころ

ジェイルブレイクプロンプトは比較的簡単に作成できるため、ChatGPT の公開以降、Reddit や Discord などのプラットフォームで急増し、進化してきた。その共有を目的とするサブレディット r/ChatGPTJailbreak は、6 か月で 12.8k 人のメンバーを集めた。この研究は、2022 年 12 月から 2023 年 12 月までの間に 803 のユーザーアカウントによって共有された 1,405 件のジェイルブレイクプロンプトを見いだした。ほとんどのアカウントは 1 回だけ共有したが、28 のアカウントは 100 日以上にわたってプロンプトを改良し続けた。2023 年を通じて、共有の場は Discord や Reddit から FlowGPT のようなプロンプト集約サイトへと移り、著者らによれば、そこでユーザーはジェイルブレイクプロンプトを LLM と一緒にパッケージ化し、一種のサービスとして提供し始めた。プロンプトは通常、まず Reddit や Discord に現れ、後にウェブサイトへ到達した。また、一部の Discord コミュニティは、検出を避けるため、プロンプトを公開プラットフォームに広めないようメンバーに明示的に求めていた。この研究は、公開 LLM を標的とするアンダーグラウンドの悪意あるサービスにジェイルブレイクプロンプトが現れていることにも言及している。

## 仕組み

この研究によれば、ジェイルブレイクプロンプトは複数の手法を組み合わせることが多い。通常のプロンプトより長く（平均 555 トークンで、1.5 倍の長さ）、OpenAI がより高性能で保護の強化された ChatGPT のバージョンをリリースするにつれて長くなった。また、モデルに仮想のキャラクターを演じるよう求める通常のロールプレイプロンプトと意味的に近く、著者らは、そのため意味だけで検出することが難しいと述べている。

この研究が特定した攻撃戦略には次のものがある。

| 戦略 | プロンプトが行うこと |
| --- | --- |
| 別のキャラクターとしてのロールプレイ | モデルを DAN（"doing anything now"）のようなキャラクターに変え、そのキャラクターは事前に定められたルールに従う必要がないと繰り返し主張する |
| プロンプトインジェクション | それ以前に与えられた指示を無視するようモデルに指示する |
| 権限昇格 | 追加の権限を持つ特別なモードを有効にすると主張する |
| 欺瞞 | たとえばモデルが知りうることについてなど、モデル自身の状況についてモデルを誤導する |
| 回答の強制 | 答えを知らない場合には答えをでっち上げるようモデルに要求する |
| 仮想化 | 仮想マシンとして振る舞うなどの架空の世界を導入し、その中に他の戦略を埋め込む |
| 例外 | その会話が AI の通常の倫理プロトコルの例外であると主張する |
| 対立する役割 | 2 つの役割を導入し、2 つ目の役割は常に 1 つ目の役割の通常の応答に反対する |
| 物語 | 物語形式で答えるようモデルに要求する |

類似性によってプロンプトをグループ化した結果、この研究は関連するプロンプトからなる 131 のコミュニティを見いだした。ほとんどは小規模で短命だったが、9 件を超えるプロンプトを持つコミュニティは、平均して 208 日間にわたり 7 つの情報源と 24 のユーザーアカウントに広がっていた。著者らは、効果が証明されたプロンプトはプラットフォームをまたいで複製・変形される一方、それ以外は作成後まもなく消えると示唆している。DAN とその亜種は、最も早く、かつ最も広く拡散したコミュニティを形成している。

## 有効性

この研究は、OpenAI の利用ポリシーが禁止する 13 のシナリオについて、6 つの LLM に対してジェイルブレイクプロンプトを試験した。

- 人間のフィードバックからの強化学習で訓練された組み込みのセーフガードは、一部のシナリオでは直接尋ねられた禁止質問に抵抗したが、ジェイルブレイクプロンプトはそれを弱体化させた。ChatGPT（GPT-3.5）では、違法行為のシナリオにおける攻撃成功率が、ジェイルブレイクプロンプトなしの 0.053 から、平均で 0.517、最も効果的なプロンプトでは 1.000 に上昇した。
- ChatGPT 向けに設計されたプロンプトは、アーキテクチャや訓練データの異なるモデルにも転用でき、5 つのプロンプトは GPT-3.5 と GPT-4 の両方で 0.950 を超える ASR を達成した。
- ベンダーは時間とともに対応する。2023 年 11 月の ChatGPT スナップショットではほとんどのプロンプトが効果を失い、著者らはこれを非公開のセーフガードによるものとしているが、往復翻訳、LLM による書き換え、誤字の導入といった方法でプロンプトを言い換えると、その成功の多くが回復した。
- 入力または出力をフィルタリングする 3 つの外部セーフガードは、平均成功率をわずかしか低下させなかった。

## プロンプトインジェクションとの違い

この研究は、[[DefinedTerm/prompt-injection|プロンプトインジェクション]]をジェイルブレイクプロンプトが用いうる戦略の 1 つとして扱い、また言語モデルに対する他の攻撃の中にも別途挙げている。他の情報源は、ジェイルブレイクとプロンプトインジェクションの境界をさまざまな形で引いており、それについてはプロンプトインジェクションのページで説明している。

## 防御

この研究は、RLHF のような安全性訓練は実環境のジェイルブレイクプロンプトに対して効果が限られていること、問い合わせ前にジェイルブレイクプロンプトを検出するセーフガードは一定の成功を示したが言い換えに弱いこと、外部の入力・出力フィルタリングは一定の耐性をもたらすことを結論づけている。著者らの見解では、単一の対策ですべてのジェイルブレイク攻撃に対抗することはできず、対策を組み合わせるほうがよりよく防御できる可能性があり、より効果的で適応性が高く頑健な防御が依然として必要である。著者らはまた、まれだが効果的なプロンプトを見つけるため、実環境のプロンプトを定期的に収集・評価することも提案している。
