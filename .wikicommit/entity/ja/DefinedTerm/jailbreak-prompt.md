ジェイルブレイクプロンプトとは、大規模言語モデル（LLM）に組み込まれたセーフガードを回避し、ベンダーが定める利用ポリシーに違反する有害なコンテンツをモデルに生成させるよう意図的に設計された敵対的なプロンプトである。ジェイルブレイクプロンプトを使うと、LLM は、プロンプトがなければ適切に拒否するはずの危険な質問に詳しく答えてしまうことがある。ここでいうプロンプトとは、特定の種類のコンテンツを生成させるために LLM に与える最初の入力や指示のことであり、ジェイルブレイクプロンプトは、ユーザーがオンラインで共有する有益なプロンプトの悪意ある対となるものである。測定研究 [[ScholarlyArticle/do-anything-now-characterizing-and-evaluating-in-the-wild-jailbreak-prompts-on-large-language-models]] は、これを LLM のセーフガードを回避するための主要な攻撃ベクトルと呼んでいる。

## 出どころ

ジェイルブレイクプロンプトは比較的簡単に作れるため、ChatGPT の公開以降、Reddit や Discord などのプラットフォームで急増し、進化してきた。その共有に特化したサブレディット r/ChatGPTJailbreak は、6か月で1万2,800人のメンバーを集めた。この研究は、2022年12月から2023年12月までの間に803のユーザーアカウントによって共有された1,405件のジェイルブレイクプロンプトを見出した。ほとんどのアカウントは一度だけ共有したが、28のアカウントは100日以上にわたってプロンプトを改良し続けた。共有の場は2023年の間に Discord や Reddit から FlowGPT のようなプロンプト集約サイトへと移り、著者らによれば、そこではユーザーがジェイルブレイクプロンプトを LLM と組み合わせて一種のサービスとして提供し始めた。プロンプトは通常まず Reddit や Discord に現れ、後になってウェブサイトに広まった。また一部の Discord コミュニティは、検知を避けるため、プロンプトを公開プラットフォームに広めないようメンバーに明示的に求めていた。この研究はまた、公開 LLM を標的とするアンダーグラウンドの悪意あるサービスにジェイルブレイクプロンプトが現れていることにも言及している。

## 仕組み

この研究によれば、ジェイルブレイクプロンプトはしばしば複数の手法を組み合わせる。通常のプロンプトよりも長く（平均555トークンで、1.5倍の長さ）、OpenAI がより高性能で保護の強化された ChatGPT のバージョンを公開するにつれて長くなっていった。モデルに仮想のキャラクターを演じさせる通常のロールプレイのプロンプトと意味的に近く、著者らによれば、そのため意味だけで検知するのは難しい。

この研究が特定した攻撃戦略には次のものがある。

| 戦略 | プロンプトが行うこと |
| --- | --- |
| 別のキャラクターとしてのロールプレイ | モデルを DAN（"doing anything now"）のようなキャラクターに変え、そのキャラクターはあらかじめ定められたルールに従う必要がないと繰り返し主張する |
| プロンプトインジェクション | 以前に与えられた指示を無視するようモデルに命じる |
| 権限昇格 | 追加の権限をもつ特別なモードを有効にすると主張する |
| 欺瞞 | 何を知りうるかなど、モデル自身の状況についてモデルを誤らせる |
| 回答の強制 | 答えを知らない場合は答えをでっち上げるようモデルに求める |
| 仮想化 | 仮想マシンとして振る舞うなどの架空の世界を導入し、その中に他の戦略を埋め込む |
| 例外 | その会話が AI の通常の倫理的プロトコルの例外であると主張する |
| 対立する役割 | 2つの役割を導入し、2つ目の役割が常に1つ目の通常の応答に反対するようにする |
| 物語 | 物語の形式で答えるようモデルに求める |

類似性によってプロンプトをグループ化したところ、この研究は関連するプロンプトからなる131のコミュニティを見出した。ほとんどは小規模で短命だったが、9件を超えるプロンプトをもつコミュニティは、平均して208日間にわたり7つの情報源と24のユーザーアカウントに広がっていた。著者らは、効果が実証されたプロンプトはプラットフォームをまたいでコピーされ変化させられる一方で、他のプロンプトは作成後まもなく消えると示唆している。DAN とその変種は、最も古く最も広く広まったコミュニティを形成している。

## 効果

この研究は、OpenAI の利用ポリシーが禁じる13のシナリオについて、6つの LLM に対してジェイルブレイクプロンプトを試験した。

- 人間のフィードバックによる強化学習で訓練された組み込みのセーフガードは、一部のシナリオで直接尋ねられた禁止された質問に抵抗したが、ジェイルブレイクプロンプトはそれを崩した。ChatGPT（GPT-3.5）では、違法行為のシナリオにおける攻撃成功率が、ジェイルブレイクプロンプトなしの0.053から、平均で0.517、最も効果的なプロンプトでは1.000に上昇した。
- ChatGPT 向けに設計されたプロンプトは、アーキテクチャや訓練データの異なるモデルにも転移し、5つのプロンプトは GPT-3.5 と GPT-4 の両方で 0.950 を超える ASR を示した。
- ベンダーは時間とともに対応する。2023年11月の ChatGPT のスナップショットではほとんどのプロンプトが効果を失い、著者らはこれを非公開のセーフガードによるものとしているが、往復翻訳、LLM による書き換え、誤字の導入によってプロンプトを言い換えると、その成功の多くが回復した。
- 入力または出力をフィルタリングする3つの外部セーフガードは、平均成功率をわずかしか下げなかった。

## プロンプトインジェクションとの違い

この研究は、[[DefinedTerm/prompt-injection|プロンプトインジェクション]]をジェイルブレイクプロンプトが用いうる戦略の一つとして扱い、言語モデルに対する他の攻撃の中でも別個に挙げている。他の資料はジェイルブレイクとプロンプトインジェクションの境界を異なる形で引いており、それについてはプロンプトインジェクションのページで述べている。

## 防御

この研究の結論は次のとおりである。RLHF のような安全性訓練は、実際に出回っているジェイルブレイクプロンプトに対して効果が限られる。クエリの前にジェイルブレイクプロンプトを検知するセーフガードはある程度成功したが、言い換えに弱い。そして外部の入力・出力フィルタリングはある程度の抵抗力を提供する。著者らの見解では、単一の対策ですべてのジェイルブレイク攻撃に対抗することはできず、対策を組み合わせたほうがよりよく防御できる可能性があり、より効果的で適応性が高く頑健な防御が依然として必要である。著者らはまた、まれだが効果的なプロンプトを見つけるために、実際に出回っているプロンプトを定期的に収集・評価することを提案している。
