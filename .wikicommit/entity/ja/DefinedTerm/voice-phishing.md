ボイスフィッシング、またはヴィッシング（vishing）とは、電話、多くの場合は Voice over IP（VoIP）による電話を用いて[[DefinedTerm/phishing|フィッシング]]攻撃を行うことである。典型的には、クレジットカード番号や、なりすまし犯罪の手口に使われるその他の情報を盗むために用いられる。固定電話のサービスは伝統的に信頼できるものであり、電話会社が把握している物理的な場所で終端され、料金の支払者に紐づいていた。現在のヴィッシング詐欺師は、法執行機関による検知を妨げるために、発信者番号の偽装や自動音声応答システムといった VoIP の機能を用いることが多い。

## 攻撃の仕組み

ほとんどのボイスフィッシング攻撃は、自動化された音声合成システムを用いて、攻撃者が管理する番号に電話をかけるよう被害者を誘導するが、生身の人間が電話をかけるものもある。詐欺師は、銀行、警察、電話会社やインターネットプロバイダー、法執行機関、内国歳入庁（Internal Revenue Service）といった正規の機関の職員を装い、個人の詳細情報や、クレジットカードの詳細や銀行口座の PIN といった金融情報を聞き出そうとする。それによって詐欺師は口座を空にしたり、なりすまし詐欺を働いたりできる場合がある。代わりに、被害者に別の口座へ送金させたり、現金を引き出して手渡させたりするよう説得する者もいる。詐欺師はまた、Microsoft や Apple の発信者番号を偽装して、それらの企業の製品のユーザーからセキュリティ上の認証情報を聞き出そうとする。詐欺師はしばしば移民や高齢者を標的とし、逮捕や国外追放の脅しのもとで数百ドルから数千ドルを送金するよう強要する。

詐欺師は通常、従来型のハッキングではなく心理的な操作である[[DefinedTerm/social-engineering|ソーシャルエンジニアリング]]を用いて、自分が演じている役割を被害者に信じ込ませ、切迫感や権威への恐れを生み出して梃子として利用する。[[DefinedTerm/audio-deepfake|音声ディープフェイク]]は、信頼できる人物から指示を受けていると人々に思い込ませて詐欺を働くために使われてきた。

| 用語 | 意味 |
| --- | --- |
| 発信者番号の偽装 | 受信者に表示される名前や番号が発信者のものとは異なるように、発信者番号を改変すること。フィッシング詐欺師は、受信者の市外局番の番号や政府の番号を偽装することが多く、そうすることで電話が見慣れたもの、あるいは信頼できるものに見え、応答されやすくなる |
| Voice over IP（VoIP） | IP 電話とも呼ばれる、インターネット経由で音声通話を行う技術。発信者が発信者番号を偽装できるため、ヴィッシングで頻繁に使われ、標的国にある VoIP サーバーは国際的な詐欺のコストを下げうる |

**開始。** 攻撃は、偽装された発信者番号からの直接の電話、事前に録音された脅迫的な留守番電話のメッセージ、番号に電話をかけるよう求めるテキストメッセージ（その通話には料金が課される）、あるいは銀行を装った電子メールから始まることがあり、その後、被害者は電話で PIN、口座番号、その他の認証情報を伝えるよう強要される。

**動機**としては、一般に金銭的な報酬、匿名性、名声が挙げられる。銀行の情報は被害者の資産へのアクセスをもたらす。個人の認証情報は、武器の入手といった活動のために身元を隠したい人々に売られることがあり、こうした匿名性は法執行機関にとって追跡が難しい場合がある。また、フィッシング詐欺師はサイバー攻撃のコミュニティでの名声を求めることもある。

## 電子メールによるフィッシングとの違い

- 携帯電話によって、攻撃者は、高齢者のように電話は持っているが電子メールを使いこなす知識のない人々にも到達できる。
- コールセンターは歴史的に個人的で機密性の高い情報を尋ねてきたうえ、多くの人は電話で話しかけてくる相手を信頼するため、機微な情報を引き出しやすい。
- 音声によるコミュニケーションは人当たりがよいものになりうるため、電子メールよりも影響力が大きい。
- 被害者は電子メールよりも電話に対してすばやく反応する。
- 電話番号はブロックするのが難しく、詐欺師は番号がブロックされても単に番号を変えればよい。

## よくある詐欺

| 詐欺 | 詐欺師が行うこと |
| --- | --- |
| なりすまし — IRS 詐欺 | IRS の職員や入国管理官を装い、被害者が負債を、たとえ被害者が実際には負っていない負債であっても支払わなければ、国外追放や逮捕をすると脅す |
| なりすまし — ロマンス詐欺 | 出会い系アプリや電話を通じて恋愛の相手候補を装ったり、緊急にお金を必要としている昔の恋人を装ったりする |
| なりすまし — テクニカルサポート詐欺 | 被害者のコンピュータに緊急のウイルスや技術的な問題があると主張し、被害者にソフトウェアをダウンロードさせて遠隔操作を手に入れ、ファイルや個人情報にアクセスしたりマルウェアをインストールしたりする。あるいは、その問題とされるものを修理するための支払いを求める |
| 債務救済と信用修復 | 債務を軽減したり信用を修復したりできる会社を装って手数料を請求する。そうすることで通常、被害者の信用スコアは下がる |
| ビジネスと投資 | 金融の専門家を装い、投資のためのお金を得る |
| 慈善 | 慈善団体のメンバーを装う。お金は直接詐欺師の手に渡る |
| 自動車保証 | 被害者の自動車の保証について電話をかけ、ときには車に関する情報を示しながら、個人情報を集めたり保証の代金を徴収したりする |
| 荷物 | 移民の集団を標的とし、刑事事件に関連する荷物について宅配業者を装い、その後被害者を外国の警察を装った共犯者に引き継ぐ。共犯者は被害者の身元が盗まれたと主張し、偽のマネーロンダリング捜査のためにお金を送るよう説得する |
| 誘拐 | 親族を誘拐したと主張し、被害者が電話を切ればその親族に危害を加えると脅す。ときには被害者に「誘拐された親族」と話をさせるが、恐怖、混乱、電話が声に与える影響によって、被害者はそれが別人だと気づけないことがある |

FBI のインターネット犯罪苦情センター（IC3）は、テクニカルサポート詐欺と政府機関へのなりすまし詐欺をコールセンター詐欺として数えている。2025年には、この2つのカテゴリーで80,000件を超える苦情を受け付け、報告された損失額は29億ドルを超えた。同年の政府機関へのなりすましに関する苦情32,424件のうち、8,628件は60歳以上の人々からのもので、その報告された損失額は413,206,251ドルであった。

## 検知と防止

銀行のような正規の機関もときに電話で機微な情報を尋ねることがあり、また被害者、とりわけ高齢者は、詐欺師が発信者番号を改変できることを知らない場合があるため、ボイスフィッシングは見分けるのが難しいことがある。

- **消費者向けの助言。** 米国連邦取引委員会（FTC）は、現金、ギフトカード、プリペイドカードで支払わないよう警告しており、政府機関が社会保障番号のような個人情報について話し合うために市民に電話をかけることはないと述べている。発信者の口調やなまり、電話の切迫性も、電話が正規のものかどうかを見極める手がかりになりうる。FTC の第一の推奨は、知らない番号からの電話に出ないことであり、電話に出てしまった場合には、促されてもボタンを押さず、不審な発信者の質問に答えないよう助言している。
- **発信者番号の認証。** 2020年3月31日、米国連邦通信委員会（FCC）は、発信者番号の偽装に依存するヴィッシングを減らすために、電話会社が発信者番号の情報を認証するためのフレームワークである STIR/SHAKEN として知られる義務を採択した。米国のすべての電話サービス提供者は、2021年6月30日までにこれを自社のインフラストラクチャに組み込む必要があった。
- **認証済みプロフィール。** 一部の国では、政府や銀行がソーシャルメディアを通じて一般の人々とやり取りしており、認証済みのプロフィールによって偽のプロフィールと区別されている。
- ボイスフィッシング攻撃に共通する特徴を見分けるための**一般向けの訓練**は、最も直接的で効果的な緩和策である。
- **ソフトウェアによる検知**は、フィッシングの電話と正直な電話を区別でき、一般向けの訓練よりも安価に導入できる場合がある。ブラックリストは単純な方法である。最近の研究では、人工知能とデータ分析を用いて正規の電話とフィッシングを区別しており、通話をテキストに変換して自然言語処理でフィッシングを特定できるようにしているほか、偽の音声を検知するための拡張や特徴量の設計も探究されている。
- **攻撃的なアプローチ**には、フィッシングの電話に偽のデータを送り込む電話アプリや、詐欺師を思いとどまらせるために法執行機関が科すより厳しい罰則が含まれる。

## 注目すべき事例

| 事例 | 何が起きたか |
| --- | --- |
| IRS なりすまし詐欺（2012〜2016年） | 詐欺グループが内国歳入庁や入国管理の職員を装って50,000人を超える人々に接触し、数億ドルと被害者の個人情報を盗んだ。米国とインドにいたとされる共謀者たちは、「逮捕、投獄、罰金、または国外追放」をちらつかせて脅した。2018年には24人の被告に判決が言い渡され、最も長いものは懲役20年であった |
| COVID-19 詐欺 | 2021年3月28日、FCC は、不正な COVID-19 関連製品に関する電話詐欺が増加していると警告した。食品医薬品局（FDA）も、COVID-19 を「予防、治療、緩和、診断、または治癒する」とうたう製品を販売する手口を監視してきた |
| ハリウッド・コン・クイーン詐欺（2015年〜） | 詐欺師がハリウッドのメイクアップアーティストや有力な女性幹部になりすまし、被害者の生活を綿密に調べ上げたうえで、何時間にもわたる電話を繰り返しかけ、払い戻しを約束して被害者にインドネシアへ渡航させ、お金を支払わせた |
| Thamar Reservoir サイバー攻撃（2015年） | イスラエルの研究者でイラン専門家の女性が、イスラエル軍ラジオでイランにつながりがあると口にした後、ペルシャ語版 BBC のインタビューを依頼する電話を受け、パスワードを求める Google ドライブの文書を開くよう言われた。これは、入手した認証情報を用いたさらなる攻撃の前段として使われたヴィッシングの電話であった |
| Mobile Bank ID 詐欺（スウェーデン） | 銀行員を装った発信者がセキュリティ上の問題があると主張し、被害者に Mobile Bank ID アプリを使うよう求めた。これにより詐欺師は、パスワードなしで被害者の口座にログインし、送金することができた。2018年、アプリはユーザーにコンピュータの画面上の QR コードを撮影させるよう変更され、電話とコンピュータが同じ場所にあることが保証されるようになり、この詐欺はほぼ根絶された |
