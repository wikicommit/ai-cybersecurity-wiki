バックドア防御とは、[[DefinedTerm/backdoor-attack|バックドア攻撃]]の脅威を軽減するための手法である。バックドア攻撃では、深層ニューラルネットワーク（DNN）に、攻撃者が指定したトリガーによって起動される隠れたバックドアが仕込まれる。[[ScholarlyArticle/backdoor-learning-a-survey]]は防御を2つの主要なカテゴリに分けている。*経験的*防御は、既存の攻撃の観察や理解に基づいており、実際にはそれなりに機能するが、理論的保証はなく、適応的攻撃によって回避されうる。*認証付き*防御は、一定の仮定のもとで理論的に保証されているが、それらの仮定は通常満たされないため、一般に実際の性能は劣る。既存の防御のほとんどはポイズニングベースの攻撃を対象としている。

## 3つのパラダイム

サーベイは、ポイズニングベースのバックドア攻撃を鍵で扉を開けることにたとえている。攻撃が成功するのは、モデルが隠れたバックドアをもち、入力がトリガーを含み、トリガーとバックドアが一致する場合に限られる。それぞれの要件から防御のパラダイムが導かれる。

| パラダイム | 断ち切るもの | 下位カテゴリ |
| --- | --- | --- |
| トリガーとバックドアの不一致 | トリガーとバックドアの一致 | 前処理ベースの防御 |
| バックドアの除去 | モデル内の隠れたバックドア | モデル再構築、トリガー合成、モデル診断、ポイズン抑制、訓練サンプルフィルタリングに基づく防御 |
| トリガーの除去 | 入力内のトリガー | テストサンプルフィルタリングに基づく防御 |

## 経験的防御

| 下位カテゴリ | 仕組み | サーベイが説明する例 |
| --- | --- | --- |
| 前処理ベース | モデルの前にモジュールを追加し、攻撃サンプル内のトリガーを変化させてバックドアと一致しないようにする | 前処理器としての事前訓練済みオートエンコーダ（この種の最初の防御）、GradCAM で見つけた影響の大きい領域を除去して修復（インペインティング）する Februus、縮小や反転などの空間変換（計算コストをほとんど増やさないため、サーベイはより効率的だとしている） |
| モデル再構築 | 疑わしいモデルを直接改変してバックドアを除去する | 破滅的忘却に依拠する、手元の良性サンプルでの再訓練、良性サンプルで休眠しているニューロンを刈り込んでからファインチューニングする fine-pruning、モード接続性、知識蒸留 |
| トリガー合成 | まずトリガーを再構築し、次に刈り込みや再訓練などによってその効果を抑える | この種の最初の防御とされる Neural Cleanse（各クラスについて候補トリガーを導出し、異常検知によって本物を選び出す）、単一のトリガーではなくトリガーの分布を復元する後続の研究、モデルの予測のみを必要とするブラックボックス版 |
| モデル診断 | メタ分類器を用いてモデルが感染しているかを判定し、感染モデルのデプロイを拒否する | メタ分類器と同時に最適化される universal litmus patterns、良性モデルのみで訓練されたメタ分類器、顕著性マップの外れ値検出、良性モデルと感染モデルのトポロジー的な違い |
| ポイズン抑制 | 訓練中に汚染サンプルの効果を弱め、バックドアが形成されないようにする | ノイズ付きまたは差分プライバシー付きの確率的勾配降下法、CutMix などの強力なデータ拡張、勾配上昇に基づく anti-backdoor learning、エンドツーエンドの訓練プロセスの分離 |
| 訓練サンプルフィルタリング | 訓練前に訓練セットから汚染サンプルを取り除く | 特徴表現の共分散に現れるスペクトルシグネチャとそれを増幅する SPECTRE 手法、活性化のクラスタリング、入力勾配や顕著性マップによるフィルタリング、汚染サンプルが残す高周波のアーティファクト |
| テストサンプルフィルタリング | 推論時に攻撃サンプルを取り除く | 疑わしい入力に画像パターンを重ね合わせ、予測のランダム性を測定する手法、モデルの不確実性、差分プライバシーに基づく外れ値検出 |

これらのいくつかは攻撃についての仮定に依拠している。トリガー合成ベースの防御や顕著性ベースの防御は、トリガーがすべてのサンプルで同じであることに依拠しているが、サンプル固有の攻撃はこれを崩す。また、ターゲット指向の防御の多くは、汚染サンプルごとに異なるターゲットラベルをもつ All-to-all 攻撃によって回避されうる。Tang らは、単純なターゲット汚染によって汚染サンプルの表現を良性サンプルのものと区別しにくくでき、ほとんどのフィルタリング防御を回避できることを示した。トリガー合成防御のほとんどはホワイトボックスであり、モデルのソースファイルへのアクセスを必要とする。

## 認証付き防御

ほぼすべての経験的防御が後の適応的攻撃によって回避されてきた、サーベイが「いたちごっこ（cat-and-mouse chasing game）」と呼ぶ状況を終わらせるため、Wang らは*ランダム化平滑化*に基づく認証付きバックドア防御への第一歩を踏み出した。ランダム化平滑化はもともと敵対的サンプルに対する頑健性を認証するために開発されたもので、入力にランダムなノイズを加えることで平滑化された関数を構築する。Wang らはその代わりに、訓練手続き全体を基底関数として扱った。Weber らは、ランダム化平滑化をそのまま適用しても高い認証済み頑健性の上界は得られないことを示し、さまざまなノイズ分布を検討する統一的な枠組みを提案した。後の研究では、有効性を高めるためにバギングなどのアンサンブル手法が用いられた。

## 防御の評価方法

- **検出型の経験的防御**（モデル診断とテストサンプルフィルタリング）は二値分類問題を解くものであり、適合率、再現率、F1 スコアで評価される。
- **その他の経験的防御**は良性サンプルと攻撃サンプルの両方を正しく予測することを目指し、良性精度と攻撃成功率で評価される。訓練サンプルフィルタリングはここに含まれる。こうした防御は、一部の良性サンプルを犠牲にしてでも、できるだけ多くの汚染サンプルを破棄しうるからである。
- **認証付き防御**は、一定の仮定のもとでいかなる摂動も予測を変えられない認証半径を提供し、良性精度、認証率、認証精度で評価される。

## 未解決の問題

サーベイは、効果的かつ効率的な防御を今後の研究の方向性として挙げている。ほぼすべての経験的防御は適応的攻撃によって回避されうること、前処理ベースのもの以外はいずれも通常高い計算コストを伴うこと、ブラックボックス防御はより実用的であるため一層の注目に値すること、そして認証付き防御はほとんど研究されてこなかったことである。
