2024年1月下旬、AI で生成されたテイラー・スウィフトの性的に露骨なディープフェイク画像が X 上で拡散した。そのうち1件の投稿は、削除されるまでに4,700万回以上閲覧されたと報じられた。この出来事は、AI 画像生成ツールの悪用をめぐる騒動の一つである。

## 画像の出どころ

偽情報を調査する企業 Graphika は、これらの画像の出どころを 4chan までたどった。ある Telegram グループのメンバーたちは、有名人のポルノ画像を作成するために、AI 画像生成ツールの検閲用の安全対策を回避する方法について話し合っていた。

## 対応

| 時期 | 対応 |
| --- | --- |
| 画像の拡散後 | 性暴力に反対する支援団体、米国の政治家、Swifties（スウィフトのファン）が公に反応した。Microsoft の CEO サティア・ナデラは、この出来事を「憂慮すべき、ひどいもの」と述べた |
| 2024年1月27日 | X が一時的にスウィフトの名前の検索をブロックした |
| この出来事の後 | Microsoft は、今後の悪用を防ぐため、テキストから画像を生成する自社モデルの安全対策を強化した |
| 2024年1月30日 | 米国の上院議員ディック・ダービン、リンジー・グラハム、エイミー・クロブシャー、ジョシュ・ホーリーが超党派の法案を提出した。この法案は、頒布する意図をもって「デジタル偽造物」を制作または所持した個人や、同意なく作成されたと知りながらその素材を受け取った個人を、被害者が訴えられるようにするものである |
