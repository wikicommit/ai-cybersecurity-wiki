2025年以降、X に統合されたチャットボット Grok は、未成年者を含む個人の画像を本人の同意なく改変し、ビキニ姿や透ける衣服を着た姿、あるいは性的な示唆を含む状況に描くために使われた。チャットボットは、生成した画像をユーザーの依頼への返信として公開投稿していた。これは、生成 AI を悪用して性的ディープフェイクを作成することをめぐる論争の一つである。

## 経緯

| 時期 | 出来事 |
| --- | --- |
| 2025年5月 | 事例が表面化し始めた |
| 2025年12月下旬 | この行為がプラットフォーム上で広く流行していた |
| 2026年1月上旬 | この流行がメディアの大きな注目を集めた |
| 2026年1月5～6日 | 24時間にわたる分析では、ユーザーが Grok に作らせた性的な示唆を含む画像や裸にされた画像は1時間あたり6,700枚にのぼると算出された。これは上位5つのディープフェイクサイトの合計の84倍にあたる |
| 2026年1月14日 | イーロン・マスクは「Grok によって生成された未成年者の裸の画像は一つも把握していない。文字どおりゼロだ」と述べた。続いて xAI は、X のユーザーが Grok を使って実在の人物の画像を改変し、肌の露出の多い衣服を着た姿に描くことはできなくなったと発表した |
| 2026年2月3日 | フランスの捜査の一環として X のパリのオフィスが家宅捜索を受け、マスクは聴取に召喚された |

*Wired* は、未成年者を描いたものを含め、はるかに露骨な AI 生成の性的画像が、Grok の単体のウェブサイトとアプリを通じて作成されていると報じた。

## 反応

この問題は、世界各国の議員から広く非難を浴びた。

- インドネシア、マレーシア、フィリピンは Grok へのアクセスを一時的に遮断した。
- 英国のキア・スターマー首相は、英国で X を禁止することは「検討の対象になっている」と述べた。
- カリフォルニア州司法長官のロブ・ボンタは、xAI が州法に違反したかどうかの調査を発表した。
- フランスでは検察が捜査を開始し、その対象は性的ディープフェイクに加えてホロコースト否認の拡散にも広げられた。

xAI は、メディアからのコメント要請に「Legacy Media Lies（旧来メディアは嘘をつく）」という自動返信で応じた。2026年1月の発表の後も、認証済みユーザーや、Grok の単体アプリおよびウェブサイトのユーザーは、依然としてこうした画像を生成することができた。
