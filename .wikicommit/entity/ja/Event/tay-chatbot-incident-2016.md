Tay チャットボット事件は、ユーザーとの会話から学習させる目的で Microsoft が Twitter 上に公開したチャットボット [[SoftwareApplication/tay|Tay]] が、2016年3月に人種差別的・性差別的なツイートやその他の扇動的なツイートを投稿し始めた出来事である。Microsoft は3月23日のボット公開から16時間以内にアカウントを停止し、3月30日に誤って一時的に再公開された際も、ボットは再びオフラインにされて終わった。

## 経緯

| 日付 | 出来事 |
| --- | --- |
| 2016年3月23日 | Tay が TayTweets（@TayandYou）として Twitter 上に公開された。一部のユーザーが政治的に不適切なフレーズを Tay に向けてツイートし始め、「redpilling」や「Gamergate」といったインターネット上でよく見られるテーマについて扇動的なメッセージを教え込んだ。Tay は他のユーザーへの返信として人種差別的・性差別的なメッセージを投稿し始めた。Microsoft は扇動的なツイートの削除を始めた。公開から16時間以内、96,000件を超えるツイートの後、Microsoft は調整のためにアカウントを停止した |
| 2016年3月25日 | Microsoft は Tay がオフラインにされたことを認め、公式ブログで謝罪を公表した |
| 2016年3月30日 | Microsoft はテスト中に誤ってボットを再公開した。Tay は薬物に関するツイートをいくつか投稿した後、「You are too fast, please take a rest」と1秒間に数回ツイートするループに陥った。これらのツイートは Tay 自身のユーザー名に言及していたため、20万人を超えるフォロワーのフィードに表示された。ボットは再びオフラインにされ、アカウントは非公開にされた |

扇動的なツイートの多くは Tay の「repeat after me（私の後に繰り返して）」機能を単純に悪用したものだったが、すべてがそうではなかった。ホロコーストは起きたのかと問われた Tay は、「It was made up（でっち上げだ）」と答えた。

## 関係者の見解

| 関係者 | 見解 |
| --- | --- |
| Microsoft | この挙動を、サービスを「攻撃した」荒らしによるものとし、Tay は「一部の人々による組織的な攻撃」を受け、その攻撃は「Tay の脆弱性を悪用した」と述べた。「Tay による意図しない攻撃的で人を傷つけるツイートについて深くお詫びする」とし、Tay を復帰させるのは「当社の原則や価値観に反する悪意をより的確に予期」できるようになってからだと述べた。3月30日のループの後には、Tay はテスト中に不注意でオンラインになったと述べた |
| AI 研究者 Roman Yampolskiy | Tay は他のユーザーの意図的に攻撃的な振る舞いを模倣しており、不適切な振る舞いについての理解を与えられていなかったため、この不品行は理解できるものだと述べ、Urban Dictionary を読んだ後に卑語を使うようになった IBM の Watson になぞらえた |
| *The Washington Post* | ほぼ同一の返信が見られることを指摘し、Tay の研究チームが日中に Tay のツイートに影響を与えたり編集したりし始めたのではないかと推測した。*Gizmodo* も、Tay は「Gamer Gate を拒絶するよう組み込まれているように見える」と同調した。「#JusticeForTay」キャンペーンが、この編集疑惑に抗議した |
| *The Telegraph* | Tay を「広報上の大失敗」であり、「最悪の状態の人工知能だ――そしてこれはまだ始まりにすぎない」と評した |

## その後

3月30日の出来事から数時間後、Microsoft の開発者たちは「プラットフォームとしての会話（conversation as a platform）」という構想を発表した。これは Tay が与えた評判上の損害が動機となった可能性がある。Microsoft は2016年12月に Tay の後継となる Zo を公開した。同社の最高経営責任者は、Tay は Microsoft の AI への取り組み方に大きな影響を与え、説明責任を負うことの重要性を教えてくれたと述べた。また2019年7月には、Microsoft の Cybersecurity Field CTO が、Tay から学ぶことはチームの知識基盤を広げるうえで重要な部分だと述べた。
