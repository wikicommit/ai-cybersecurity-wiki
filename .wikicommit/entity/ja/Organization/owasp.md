OWASP（Open Worldwide Application Security Project、旧称 Open Web Application Security Project）は、IoT、システムソフトウェア、Web アプリケーションのセキュリティに関するオープンソースの情報とリソースを公開しているオンラインコミュニティである。非営利団体の OWASP Foundation が主導し、業界標準、カンファレンス、ワークショップを通じて活動している。2017年の時点で約13,000人のボランティアがいた。

## 公開しているもの

### OWASP Top Ten

Top Ten は、最も重大なアプリケーションセキュリティリスクの一覧である。2003年に初めて公開され、定期的に更新されている。

| 版 | 出典に記録されている内容 |
| --- | --- |
| 2003 | 初版 |
| 2004、2007、2010、2013、2017、2021 | その後の版 |
| 2025 | 出典が挙げている最新の版。ソフトウェアサプライチェーンの不備を含む新たなカテゴリーを導入した |

MITRE、PCI DSS、国防情報システム局（DISA-STIG）、米国連邦取引委員会をはじめ、多くの標準、書籍、ツール、組織が Top Ten を参照している。2023年5月、OWASP は、大規模言語モデルに関連する最も重大なリスクを文書化するよう Top Ten リストの対象範囲を広げるため、OWASP Gen AI Security Project を開始した。

### その他のリソース

| 種類 | リソース |
| --- | --- |
| ツール | ペネトレーションテストツールの OWASP ZAP、安全なプログラミングの実践の手引きとして作られた、意図的に脆弱な Web アプリケーションの WebGoat |
| ガイド | Development Guide、Testing Guide、Code Review Guide、Top 10 Incident Response Guidance |
| モデルと標準 | Software Assurance Maturity Model（SAMM）、アプリケーションレベルのセキュリティ検証のための標準である Application Security Verification Standard（ASVS） |
| その他のプロジェクト | XML Security Gateway Evaluation Criteria Project、AppSec Pipeline、Automated Threats to Web Applications、API Security Project、AI Maturity Assessment Project（AIMA） |
| 認定資格 | Web アプリケーションセキュリティに焦点を当てた、Top 10、ASVS、SAMM、Security Knowledge Framework（SKF）の認定資格 |

## 歴史

- **2001年** — マーク・カーフィー（Mark Curphey）が2001年9月9日に OWASP を立ち上げた。
- **2003〜2011年** — ジェフ・ウィリアムズ（Jeff Williams）が2003年末から2011年9月まで、ボランティアの議長を務めた。
- **2004年** — OWASP Foundation が米国で 501(c)(3) 非営利団体として設立された。同財団は OWASP の基盤とプロジェクトを支えている。
- **2011年** — OWASP はベルギーでも、OWASP Europe VZW として非営利団体の登録を行った。
- **2023年** — 2月、OWASP Foundation のグローバル理事会の役員が、理事会がプロジェクトの名称を Open Web Application Security Project から現在の名称に変更すること、すなわち「Web」を「Worldwide」に置き換えることを議決したと報告した。5月には OWASP Gen AI Security Project が開始された。
