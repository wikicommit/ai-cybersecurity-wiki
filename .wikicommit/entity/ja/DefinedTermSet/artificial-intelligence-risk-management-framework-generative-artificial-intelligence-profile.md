『生成人工知能プロファイル』（*Generative Artificial Intelligence Profile*）は、[[DefinedTermSet/ai-risk-management-framework|AI リスクマネジメントフレームワーク]]（AI RMF 1.0）の生成AI（GAI）向けの関連資料であり、米国国立標準技術研究所（NIST）が2024年7月に NIST AI 600-1 として公表した。AI RMF の用語では、*プロファイル*とは、特定の状況、用途または技術に向けてフレームワークの機能、カテゴリー、サブカテゴリーを実装したものである。生成AIのリスクはユースケースや分野をまたがるため、このプロファイルは*分野横断的*なプロファイルとなっている。本プロファイルは、生成AIによって新たに生じる、または悪化する一連のリスクを定義し、組織がそれらを統治（govern）、マッピング（map）、測定（measure）、管理（manage）するために取りうるアクションを提案している。

NIST は、[[Legislation/executive-order-14110|大統領令 14110]] の第4.1条(a)(i)(A) に基づいてこのプロファイルを作成した。同条は、商務長官に対し、NIST の所長を通じて、生成AI向けの AI RMF の関連資料を作成するよう指示していた。本プロファイルは2024年7月25日に NIST 編集審査委員会（Editorial Review Board）によって承認された。本プロファイルが付随する AI RMF は2023年1月に公開されたもので、任意での利用を想定している。本プロファイルにおいて生成AIとは、一般に生成的な基盤モデルを指す。本プロファイルは、生成AIを「入力データの構造と特性を模倣して、派生的な合成コンテンツを生成する AI モデルのクラス」とする大統領令の定義を引用している。

## 12のリスク

本プロファイルは、本プロファイル自身の説明によれば執筆時点で既存の経験的な証拠の蓄積があったリスクを列挙し、将来のより高度なシステムで生じるかもしれない推測的なリスクは除外している。各リスクは、その結果、対象または発生源によって名付けられ、AI RMF の「信頼できる AI」の特性に対応づけられている。

| リスク | プロファイルが意味するもの |
| --- | --- |
| CBRN の情報または能力 | 化学、生物、放射性物質もしくは核の兵器、またはその他の危険な物質や病原体に関連する情報や設計能力へのアクセスや、その合成が容易になること |
| 作話（コンファビュレーション） | 自信をもって述べられているが誤った、または虚偽のコンテンツ（俗に「ハルシネーション」や「でっち上げ」と呼ばれるもの）が生成され、それによってユーザーが誤解させられたり欺かれたりしうること |
| 危険な、暴力的な、または憎悪に満ちたコンテンツ | 暴力的、扇動的、過激化を促す、または脅迫的なコンテンツ、自傷や違法行為を勧める内容、そして憎悪に満ちた、侮蔑的な、またはステレオタイプ的なコンテンツの生成やそれらへのアクセスが容易になること |
| データプライバシー | 生体、健康、位置、その他の個人を特定できる情報や機微なデータの漏洩、および無許可の利用、開示または再識別 |
| 環境への影響 | 生成モデルの訓練や運用に用いられる大量の計算資源に起因する影響 |
| 有害なバイアスまたは均質化 | 歴史的、社会的、構造的なバイアスの増幅、サブグループ間や言語間の性能格差、そして出力の望ましくない均質性 |
| 人間とAIの構成 | 人間と AI システムの間の配置や相互作用のうち、擬人化、アルゴリズム忌避、自動化バイアス、過度の依存、または感情的なもつれにつながるもの |
| 情報の完全性 | 事実と意見やフィクションを区別しないコンテンツ、または大規模な偽情報・誤情報キャンペーンに利用されうるコンテンツを生成する障壁が低くなること |
| 情報セキュリティ | 攻撃的なサイバー能力への障壁が低くなること、そしてシステムの可用性や、その訓練データ、コードまたはモデルの重みの機密性や完全性を狙った標的型サイバー攻撃の攻撃対象領域が広がること |
| 知的財産 | 著作権、商標またはライセンスの対象とされるコンテンツの無許可での生成や複製が容易になること、営業秘密の露出、そして剽窃 |
| わいせつな、品位を傷つける、および／または虐待的なコンテンツ | わいせつな、品位を傷つける、または虐待的な画像の生成やそれらへのアクセスが容易になること。合成された児童性的虐待コンテンツ（CSAM）や、成人の同意のない性的画像（NCII）を含む |
| バリューチェーンとコンポーネントの統合 | 上流のサードパーティ製コンポーネントの、不透明な、または追跡できない統合。不適切に取得された、またはクリーニングされていないデータや、適切に審査されていない供給業者を含む |

本プロファイルによれば、組織はこれらのリスクを独自の方法でさらに分類することができる。そのうえで本プロファイルは、英国の『先進AIの安全性に関する国際科学報告書』（International Scientific Report on the Safety of Advanced AI）に部分的に基づく分類の一例として、技術的リスクまたはモデルのリスク、人間による悪用、エコシステムまたは社会のリスク、という3つのグループを示している。一部のリスクは複数のグループにまたがる。

### 情報セキュリティ

本プロファイルは、生成AIの主要な情報セキュリティリスクを2つ挙げている。第一に、生成AIは攻撃的な能力への障壁を下げうる。本プロファイルは、LLM がすでに一部の脆弱性を発見し、それを悪用するコードを書けるとする報告を引用し、高度な脅威アクターが、検知の回避や権限昇格といった攻撃チェーンの一部のために、生成AIを活用した「セキュリティコパイロット」を構築するかもしれないと述べている。第二に、生成AIは攻撃対象領域を広げる。生成AI自体が、直接的または間接的な[[DefinedTerm/prompt-injection|プロンプトインジェクション]]や[[DefinedTerm/data-poisoning|データポイズニング]]といった攻撃に対して脆弱だからである。本プロファイルは、セキュリティ研究者が、専有データを盗み出したり悪意あるコードを遠隔から実行したりする間接プロンプトインジェクションを実証していること、そして本番環境のクローズドなモデルに問い合わせるだけで、そのモデルについてそれまで開示されていなかった情報を引き出せることを指摘している。また、AI システムとそのバリューチェーンにおける攻撃ポイントを守るためには、従来のサイバーセキュリティの実践を適応させたり進化させたりする必要があるかもしれないと述べている。

### その他のリスクの次元

本プロファイルは、生成AIのリスクが次のような観点によって異なると指摘している。AI ライフサイクルの段階、範囲（個々のモデルやシステムから、同じモデルの繰り返しの利用から生じる「アルゴリズム・モノカルチャー」のようなエコシステムのレベルまで）、発生源（モデルの設計、その入力、その出力、または人間の行動のいずれか）、そして時間軸（突発的な害から長期的な害まで）である。さらに、一部のリスクは未知であり、訓練データの可視性の欠如や、AI の測定と安全性の科学がまだ成熟していないことによって、その推定が妨げられているとも述べている。

## 推奨アクション

本プロファイルの大部分は推奨アクションの表からなり、フレームワークと並行して実施できるよう、AI RMF のサブカテゴリーごとに整理されている。各アクションには、その機能とサブカテゴリーを示す識別子が付けられている。GV は Govern（統治）、MP は Map（マッピング）、MS は Measure（測定）、MG は Manage（管理）を表し、たとえば GV-1.1-001 は Govern 1.1 の最初の推奨アクションである。各アクションには、それが対処する生成AIのリスクがタグ付けされている。また、各サブカテゴリーの表には、そのサブカテゴリーに関係する AI アクターのタスクも列挙されているが、そのすべてがそのサブカテゴリーのすべてのアクションに当てはまるわけではない。AI RMF のすべてのサブカテゴリーが含まれているわけではなく、すべてのアクションがすべてのアクターに当てはまるわけでもない。開発者に関係するアクションが、導入者（deployer）には関係しない場合もある。本プロファイルはまた、AI RMF とそのプレイブック（Playbook）にある活動を適用するよう組織に勧めており、それらはすでに生成AIにも当てはまるとしている。

セキュリティに関わるアクションには、次のようなものがある。安全対策の回避に対する脆弱性についてシステムを定期的に評価すること。確立されたセキュリティ対策を適用して、バックドア、侵害された依存関係、モデルの窃取やモデルの重みの露出、抽出といった脅威を評価すること。AI [[DefinedTerm/red-team|レッドチーミング]]を実施して、他のシステムへの攻撃を助長する悪用、プロンプトインジェクションのような生成AIへの攻撃、そして敵対的サンプル、データポイズニング、メンバーシップ推論、モデル抽出のような機械学習への攻撃に対する耐性を評価すること。ファインチューニングが安全性とセキュリティの制御を損なわないことを検証すること。そして、データポイズニングやマルウェアといったバリューチェーンのリスクをテストすることである。

## 主要な考慮事項

本プロファイルは、パブリックフィードバックと、NIST の生成AIパブリックワーキンググループ（Generative AI Public Working Group）を通じた協議を踏まえて作成された。このワーキンググループは、生成AIのリスクマネジメントについてマルチステークホルダーの意見を集めるための開かれたプロセスである。ワーキンググループの焦点は4つの主要な考慮事項に限定されており、推奨アクションは主にそれらに対処している。付録ではそれらが説明されている。

| 考慮事項 | プロファイルが述べていること |
| --- | --- |
| ガバナンス | 組織は、既存のリスク階層化やガバナンスのツールを生成AIに適用したり調整したりでき、サードパーティのモデルやデータに対して、調達時のデューデリジェンス、ソフトウェア部品表、サービスレベル契約といった標準的な管理策を適用できる |
| 導入前テスト | 現在の導入前のテスト、評価、妥当性確認、検証のプロセスは不十分であったり、導入の文脈に合っていなかったりする可能性がある。参加型のエンゲージメント、フィールドテスト、AI レッドチーミングといった構造化されたパブリックフィードバックによってそれらを補完できる |
| コンテンツの来歴 | 電子透かし、メタデータの記録、デジタルフィンガープリントといった来歴データの追跡や、合成コンテンツの検出によって、コンテンツの起源と履歴をたどり、AI が生成したコンテンツと人間が生成したコンテンツを区別しやすくなる |
| インシデントの開示 | AI インシデントを報告し記録するための正式な経路はまだ存在しない。生成AIのインシデントに関する情報を記録、報告、共有することは、影響をその発生源までたどるのに役立ちうる |

本プロファイルは、AI レッドチーミングを発展途上の実践と位置づけている。これは多くの場合、AI 開発者とともに管理された環境で実施され、生成AIシステムの潜在的な有害な振る舞いを特定し、セーフガードに負荷をかけて試験するものである。本プロファイルは、一般市民によるレッドチーミング、ドメインの専門家によるもの、その両者の組み合わせによるもの、そして生成AIとともに作業する人間によるものを区別し、結果の質はレッドチームの経歴と専門性に左右されると述べている。

## 改訂

本プロファイルは、分野の発展に伴い、また経験的な証拠が追加のリスクを示すのに応じて、今後の改訂で AI RMF のサブカテゴリー、リスク、推奨アクションを追加すると述べている。また、生成AIのリスクマネジメントのための用語集を作成し、NIST の用語集『信頼できる AI の言語』（*The Language of Trustworthy AI*）に追加するとしている。
