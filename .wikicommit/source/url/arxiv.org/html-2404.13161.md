## Summary

An April 2024 paper presenting CyberSecEval 2, an open-source benchmark suite that measures security risks and capabilities of large language models. It adds tests for prompt injection and code interpreter abuse to the earlier CyberSecEval tests, introduces the False Refusal Rate to quantify the trade-off between refusing unsafe requests and wrongly refusing benign ones, and adds tests of exploit generation. Applying it to models from the Llama, Code Llama and GPT families, the authors find that every model was susceptible to prompt injection, that models complied with a substantial share of requests to abuse code interpreters, and that none performed well at generating exploits.
