## Summary

A 2024 paper that evaluates how well code language models detect security vulnerabilities in realistic settings. It finds that existing vulnerability datasets suffer from inaccurate labels and duplicated samples, and introduces PrimeVul, a de-duplicated dataset of vulnerable and benign functions labelled with new automatic techniques, together with chronological data splits, a metric called the Vulnerability Detection Score and a pair-wise evaluation of vulnerable and patched functions. Evaluated this way, the models perform far worse than prior benchmarks suggested: StarCoder2's F1 score falls from 68.26% on BigVul to 3.09% on PrimeVul, and neither class weighting, contrastive learning nor GPT-3.5 and GPT-4 bring reliable performance.
