## Summary

"Prompt Injection attack against LLM-integrated Applications" (Liu et al., arXiv:2306.05499) studies prompt injection against commercial applications built on large language models. A pilot study on ten applications finds that existing direct, escape-character and context-ignoring injections mostly fail, because applications treat user input as data, enforce input and output formats, or run multi-step processes with time limits. The authors then propose HouYi, a black-box technique modelled on SQL injection and XSS that builds an injected prompt from a framework, a separator and a disruptor component and refines it from the application's responses; applied to 36 applications it found 31 vulnerable, with ten vendors, including Notion, confirming the findings, and the authors report that common prompt-level defences did not stop it.
