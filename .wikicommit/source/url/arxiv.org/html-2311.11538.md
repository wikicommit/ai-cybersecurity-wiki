## Summary

"Assessing Prompt Injection Risks in 200+ Custom GPTs" (Yu et al., arXiv:2311.11538) tests user-built custom versions of ChatGPT for two prompt-injection risks: extraction of the designer's system prompt and leakage of the files the designer uploaded. Applying simple adversarial prompts to 216 custom GPTs, with up to three attempts each, the authors extracted the system prompt in 97.2% of cases and the files in every case where files existed, and report that the custom GPT interface also exposed uploaded file names and plugin designs through its API. In a red-teaming evaluation against defensive prompts, at least one of four expert authors bypassed the defence in every setting within ten attempts, leading the authors to conclude that disabling the code interpreter helps but that defensive prompts alone are inadequate.
