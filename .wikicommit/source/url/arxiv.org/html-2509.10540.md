## Summary

This 2025 case study analyses EchoLeak (CVE-2025-32711), a zero-click prompt injection vulnerability in Microsoft 365 Copilot that let a remote attacker exfiltrate data from a victim's Copilot context by sending a single crafted email, chaining bypasses of the XPIA classifier, link redaction and the content security policy. It sets out the disclosure timeline, maps each attack step to OWASP and NIST controls, and proposes defences such as prompt partitioning, provenance-based access control, output validation and strict content security policies, arguing that the exploit moved prompt injection from a theoretical risk to a demonstrated one.
