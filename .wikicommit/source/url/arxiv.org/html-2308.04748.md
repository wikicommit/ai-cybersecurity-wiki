## Summary

"Fuzz4All: Universal Fuzzing with Large Language Models" (Xia et al., ICSE 2024) presents Fuzz4All, a fuzzer that uses large language models as its input generation and mutation engine so that it can target systems taking many different programming or formal languages as input, rather than one language or one version of it. It combines an autoprompting step, which distils user-provided documentation or examples into a concise prompt, with a fuzzing loop that keeps updating the prompt with earlier inputs and generation strategies. Evaluated on nine systems across C, C++, Go, SMT2, Java and Python, it reached higher coverage than language-specific fuzzers (36.8% on average) and found 98 bugs, 64 of them confirmed by developers as previously unknown.
