## Summary

OWASP Top 10 for LLM Applications version 1.1, published by OWASP on 16 October 2023, lists the ten most critical security vulnerabilities in applications built on large language models, from LLM01 Prompt Injection to LLM10 Model Theft. For each entry it gives a description, common examples, prevention and mitigation strategies, example attack scenarios and reference links. The list was drawn up by an international team of nearly 500 experts, who narrowed 43 proposed threats down to ten through rounds of voting and public review.
