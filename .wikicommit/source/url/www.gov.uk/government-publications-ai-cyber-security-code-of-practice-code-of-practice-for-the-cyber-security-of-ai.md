## Summary

The Code of Practice for the Cyber Security of AI is a voluntary code published by the UK government on 31 January 2025 that sets baseline cyber security requirements for AI systems, intended to help create a global standard in the European Telecommunication Standards Institute (ETSI). Arguing that AI differs from software in risks such as data poisoning, model obfuscation and indirect prompt injection, it defines the stakeholders in the AI supply chain (Developers, System Operators, Data Custodians, End-users and Affected entities) and sets out thirteen principles, made up of "shall" and "should" provisions, across five lifecycle phases: secure design, secure development, secure deployment, secure maintenance and secure end of life. It builds on the NCSC's guidelines for secure AI development, was endorsed by most respondents to a 2024 call for views, and is accompanied by an implementation guide.
