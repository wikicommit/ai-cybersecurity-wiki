The source says the intervention "involves the development of a voluntary Code of Practice which will be used to help create a global standard in ... ETSI", but it never calls the Code the "first part". The order follows from the source's wording, yet the word "first" is the page's inference. "One part" or "part of" would match the source more closely.
properties.description says the Code "assigns each [principle] to the stakeholders ... primarily responsible for it", and the body says the same, repeating the source's own statement in its Audience section. However, the page's own principles table gives "(not stated)" for Principle 10, which is correct: the source gives no "Primarily applies to" line for it. So "each" does not quite hold for the page's own table.
